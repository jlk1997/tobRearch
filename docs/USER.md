# 蜂算科研用户手册

产品名：**蜂算科研**。这是实验室的科研工作台，不是单机演示。OpenLens 只作为底层引擎。

## 加入

**申请开通机构（无邀请时）：** 打开 `/apply`，填写机构名称、类型、联系人、申请说明与登录邮箱密码，勾选全组都能看见。提交后账号即可登录，但工作台锁定，只能看「开通进度」；平台运营在 `/admin` 通过后，申请人自动成为本机构第一间空实验室的导师，可邀请成员。驳回后须在开通进度修改说明并重新提交，运营不能跳过重提直接通过。机构停用期间工作台锁定，导师仍可进成员页清理未用邀请；恢复后开通进度会自动刷新进工作台。若提示「已开通但未加入实验室」，请打开导师发来的邀请链接。邀请只能加入本机构实验室，不能用同一邮箱跨机构，也不能对同一邮箱重复发出未用邀请。

**受邀加入：** 导师发出邀请邮件或链接。打开 `/invite/{token}` 会看到实验室名称、角色与全组都能看见条款；邮箱须与邀请一致。**若该邮箱已有账号**（例如已在本机构另一实验室），登录后点「同意并加入」，不会再要求注册。新人勾选同意后设密码（至少 8 位且同时包含字母和数字）。已使用或过期的邀请会明确提示，而不是空白表单。一人一邮箱一机构，不能拿 A 机构账号去接 B 机构邀请。

登录页文案：没有账号请申请开通机构，或打开邀请链接。

## 界面

登录后左侧按 **工作台 / 科研资产 / 实验任务 / 协作 / 账户** 分组；每组先显示主路径，其余在「更多」。导师登录后进入进度，学生进入首页。顶栏切换实验室同样按角色落地；顶栏可搜文献（题名 / 作者 / DOI）/ 手稿 / 任务 / 方向 / 组会 / 数据集 / 资料 / 日志并跳到现有详情（不是新搜索站）。框是浅底深字；`/` 或 Ctrl+K 可聚焦。没有组内对象时去文献检索。通知铃铛可下拉最近未读，点标题进入对应文献、手稿或任务；文献通知可「查看复现」或「去复现」，并标已实测 / 尚无实测。页面上方有面包屑。详细交互见 `docs/UI.md`。

## 日常路径

- **首页**：当前实验室待办、在读、跑行摘要；加入后可选择研究方向，并可再挂其他方向（主方向仍是文献调研快照）。学生页顶「下一步」只谈你自己：选方向、打开本方向文献库标为在读（主方向是父时读子课题也算已开读，链接仍只带主方向；按是否有在读计，不是首页预览 8 条）、给自己的稿写相关工作（扫全部手稿，不按预览前 6 篇截断）、若自己的稿把未测写成成功则打开该稿去复现、若自己的文献调研失败（或暂停且已写出综述）仍未点名则打开该任务恢复并写出题名（相关工作已点名则写清综述仍未点名）、额度将满、工人未开；不是排名。综述还没写出来的暂停不算未点名。导师「进行中」宫格在有未点名时落到 `runs?unused=1`。每条下一步单独一行。导师打开工作台时看到与周报同一套「卡住」摘要（无人在读 / 未写相关工作 / 综述没写到），不催导师自己开读，也不按还没做完排序。宫格「在读 / 手稿」右上角不再一律写「全部」：有卡住时落到带方向或过滤的现有列表，文案写成「无人在读 / 未写相关工作 / 核心文献还没写进正文 / 还没复现就写成成功」。可写三句工作日志（自愿，不是监控）。宫格前「待处理」只在有临近节点或等 GPU / 缺数据时出现，截止日期用「还有 N 天」而不是原始时间戳。未读通知可点进对应文献 / 手稿或任务；文献通知会回到你上次读到的页，并可「去复现」。最近阅读优先显示正在读，点标题回到上次页码，并可「去复现」；手稿可「去写作」，未写相关工作会标明。来自组会的指派可回纪要对应行。
- **进度**：全组在读、手稿摘要、实验任务状态，以及可复算的在读进度（仅正在读，想读另计）、方法卡数、手稿停留天数、等待实验算力 / 缺数据计数。顶部六句态势空库时写下一步，不是空白；额度将满提示联系导师或管理员调预算，不伪造指标；工人未开且有已入队时点进待处理，不把等待写成失败。诚实句与风险句会写综述没写到次数，点进现有 `runs?unused=1`，不是排名。态势下可见与周报同一套还没做完，点进无人在读 / 未写相关工作 / 综述没写到列表。成员卡可见「谁还没做完」（尚未开读、未写相关工作、已写但仍未写到核心文献文献、综述没写到、学位过期等），按该成员全部手稿计，不按卡上预览 3 篇截断，点进现有列表，不按还没做完排序。成员进展会用同一套可点芯片写出未点名题名。还没复现就写成成功打开该成员的那篇手稿。手稿摘要可标「未写相关工作 / 核心文献还没写进正文 / 还没复现就写成成功」。统计成员行同样可见核心文献还没写进正文 / 还没复现就写成成功 / 综述没写到，前两列进该成员自己的手稿过滤（`owner_id`），未点名进现有 `runs?unused=1`，不是全组排行；还没做完合计仍不含这三列，与方向行同一口径。网格前与首页同口径的「待处理」条（导师看全组节点，含待认领）。最近动态看全组，不跟方向走。动态流断开后可重连。点成员卡片看时间线（接实验室进度接口）；点标题进入正文（三击内到达）。在读可「去复现」（打开该生上次页，不是导师自己的进度）。不做排名红灯。统计页有从文献到发表与趋势图，筛选写进网址，导出 CSV 带同一窗口；按父方向看趋势时，更早的日行可能只计本节点，页上写清没有回填，不改写历史；图元与流失芯片点进现有过滤，可切同一数字的表格；分母为零写「暂无」；空漏斗是页英雄。进度 / 周报 / 研究方向可见同一套漏斗流失与覆盖。进度可见成员阶段覆盖与方向层级，休学/已毕业进「历史成员」。周报有相对上周的对比条。
- **文献库**：检索（可勾选 arXiv / PubMed / Semantic Scholar / Google Scholar / 本实验室库；来源会写进网址；若筛了方向会叠该范围关键词，父方向含子课题，无效方向不叠全库词）无结果时提示换 PubMed / Semantic Scholar、打开捕手或上传 PDF（父方向空了写「含子课题」，换源/捕手仍带同一方向），不假装知网全文库。也可 DOI / BibTeX / CSV / 手工入库 / **多 PDF 拖入**；可按方向（父方向含子课题）、在读状态（含组内无人在读）、方法卡有无、已发表手稿引用、复现诚实状态（已有实测 / 尚无实测含缺数据 / 等 GPU / 尚未复现）过滤（过滤会写进网址，便于分享）并导出 BibTeX。从研究方向或统计点「无人在读 / 无方法卡」会落到同一套过滤。从成员卡点「尚未开读」只看**该成员**还没标在读的篇目（网址带 `reader_id`），不要和组内无人在读混在一起。文献库也可按下拉选读者；该生未读或组内无人在读空了会提示去检索，不新开阅读产品。入库默认可标为在读；若当前筛了方向，入库会挂到该方向。重复入库会提示「库中已有」。网址 `tab=recommend` 可直接打开「按方向推荐」（周报与方向页也可点进）。「按方向推荐」会按本组方向、方法卡与题录重排开放源（不只 arXiv），列出尚未入库的结果、本方向还没读的已入库篇目，以及题录匹配但未挂本方向的组内文献（可一键挂上）；若配了 rerank 模型会标明，未配则保持组内语料序。库表与推荐里已入库的篇目可回上次页并「去复现」。可选至少两篇做对比，对比卡可「去复现」进该文献的复现列表；导师把短综述写入方向说明（相同内容再点一次不会重复粘贴），作者可「写回相关工作」（计入卡住口径，并点名所选篇目题名，便于主张追踪）或写入「文献对比与差距」节（不算已写相关工作）。写回成功条与译润同一套，可写已点名几篇核心文献，并给出下一步。阅读器侧栏在读条始终可见，方法卡 / 笔记 / 辅导用 `?panel=` 分栏（不新开辅导页）；从笔记或辅导会话进入会先打开对应栏，当前页笔记排在最前。**精读辅导**针对当前页提问，侧栏是正序对话气泡（不是最新回答再列一遍历史）；同一会话会记住上一问并写进网址，可用下拉或「新会话」另起，可选写回笔记；本会话问答可翻更早的记录，别人的辅导不会出现在你的侧栏。辅导历史按这篇文献和你本人，不按方向切；方向词只进这一问。阅读器翻译只对本页或摘要做对照卡，空页不请求，译文不展示思考过程，发送中可停。自己的笔记可去译润（带绑定页），写回后仍回阅读器该页的笔记栏。辅导无依据时该条气泡会警告并可填入下一问、重新回答；回答里的 `[p.N]` 可点回 PDF。方法卡摘录须能点回页码，无依据摘录会标明；超长 PDF 会分块生成再合并，模型没返回可用 JSON 时不会把垃圾原文装进方法卡。无 PDF、仅摘要或扫描件时侧栏会写清下一步（上传可复制 PDF / 再生成方法卡），不要当成分析坏了。录入者或导师可删除条目。已发表手稿加入文献库后，阅读器会标明来源。
- **方向**：列表可见卡住 / 无人在读 / 未写相关工作 / 核心文献还没写进正文 / 还没做复现 / 还没复现就写成成功 / 综述没写到，还没做完合计与统计方向行同一口径且不含未点名，数字进过滤列表或枢纽，不按还没做完排序。可挂子课题（两级），父行写「含子课题 N」，计数含子课题；负责人可见可改。树形展开，不是独立地图页。点方向行打开详情（论文、在读成员、手稿、近期动态、学位节点），顶部可见「谁还没做完」：无人在读、还没方法卡、手稿没写相关工作、核心文献未点名、还没做复现、还没复现就写成成功、综述没写到、学位过期。未点名题名用同一套可点芯片，只记创建时记下的方向。顶栏「本方向文献库 / 手稿」在有卡住时改成对应过滤文案，不假装看完全方向。卡住按该方向全部手稿计，不按预览 20 篇截断。数字进带过滤的现有列表（无人在读 / 无方法卡 / 未写相关工作 / 核心文献还没写进正文），综述没写到进 `runs?unused=1&direction_id=`，只看该方向成员的任务，不是全组。「核心文献还没写进正文」数字是仍缺点名的手稿篇数，与列表条数一致，不排行。导师可看到尚未开读的学生姓名，以及该生还没开读的篇名（别人在读的篇仍可出现，不要和实验室无人在读混在一起），并进进度时间线或该人未读列表。再深链到本方向文献库 / 组内相关推荐 / 手稿 / 图谱。手稿行可标「未写相关工作 / 核心文献还没写进正文 / 还没复现就写成成功 / 综述没写到」并去写作或主张追踪。开题 / 中期 / 答辩记在方向与手稿上，可填截止日期，没有独立学位页。抽屉里的论文标题回到你上次页码，并可「去复现」。在读人数不含「想读」。禁止单独的地图或归档页。
- **捕手**：在选项页用邮箱登录（或粘贴三段 JWT）。导入时若令牌过期会自动刷新。在已打开且有权访问的论文页点「导入本页」。扩展会提交页面 HTML 供服务端解析 Highwire / JSON-LD / 页面标题；知网 / IEEE 元数据不完整时会降级入库并提示改用 PDF。库中已有同一 DOI / arXiv 时提示已存在。禁止付费墙绕过。
- **手稿 / 写作**：组内可互看正文，仅作者保存；导师可删除。列表显示作者姓名，可按方向、作者、「未写相关工作」、「核心文献还没写进正文」或「还没复现就写成成功」筛选，并可「去写作」。这些卡住过滤会改页头，不要假装在看全部手稿。从统计点某位成员的卡住数字会带上该成员。相关工作只认标题行。引用可增删并导出 refs.bib。侧栏用 `?tab=` 分栏（主张 / 引用 / 评论 / 评审 / 版本），有批注深链时先开评论。「主张追踪」对照 `\cite{key}` / `[@key]` / 词边界是否出现在正文，以及文献方法卡里的主张是否写入；正文只点名题名、没进参考文献也会列出并标「正文点名、未进参考文献」。页顶与主张栏同一套「还没复现就写成成功」警告，并可「去复现」；核心文献还没写进正文可「去写作点名」。点主张或文献标题会打开阅读器对应页，阅读器可「回手稿」。每条引用可「查看复现」或「去复现」。从写作页或通知点一条批注会打开 `/manuscripts/:id?comment=` 并滚到该评论。参考文献表显示你的在读进度。状态含草稿、组内评审、已投稿、返修、已发表、拒稿。已发表可「加入文献库 / 知识库」（重复点击不会复制条目）。可导出 Overleaf zip（另含 `reproduce_gaps.md`，不写进正文）。正文把尚未实测的文献写成成功时页顶警告，不拦保存。写作页可生成大纲与章节（选题会写进网址；发送中可停；已有草稿可「改写本章」而不另起一章。已选文献芯片回上次页并可去复现。有文献时附引用，卡片显示在读百分比、可跳页、可去复现；选手稿时会补参考文献，不自动改正文）。生成大纲后页上写出下一步：已选手稿则写相关工作，未选则从大纲创建手稿。从大纲创建手稿后下一步改成写相关工作（生成大纲不会自动建稿）。撰写本章会叠当前方向（含子课题）关键词，并只问该范围知识库。撰写章节后页上写出下一步：写回手稿，或先选手稿。选手稿后若本方向核心文献还没写到，页顶与主张追踪同一套提示（手稿挂父方向时含子课题已钉核心），可打开 `?tab=claims`。若自己上次文献调研失败且综述没写到，写作页与主张追踪会写出那些题名并打开该任务；生成不会自动改正文。写相关工作或写回时会点名所选篇目题名；成功条与译润同一套，并可写已点名几篇核心文献。写回成功后若这篇仍把未测写成成功，成功条下一步打开该稿去复现；若还缺写到核心文献文献，下一步进主张追踪。并用已有「模拟评审」写入导师式批注（**非官方查重**；再点一次会替换上次结构批注而不是叠评论，并标出未在正文点名的引用 key）。若提示手稿已被更新，页内刷新当前稿后再保存，以免覆盖。
- **知识库 / 译润**：上传资料问答（引用须来自原文片段）。可用方向选择器只问本方向（含子课题）已索引文献，空了写「本方向还没有已建索引的文献」并链到本方向文献库，不假装整个库空。知识库用 `?tab=` 分开文档、问答与术语，不堆在一页。向量优先走凭据上的 embedding；未接向量模型时用简易检索。片段可点「有用」记进动态，下次检索会优先。索引失败可重试切块。综述与问答引用可回上次页并可去复现。术语可锁定/解锁/删除；术语表是全实验室，不跟方向筛选走，不要当成某个方向的词表。译润页可载入手稿或笔记再润色或翻译；可用芯片填入本页 / 摘要 / 本页笔记，运行中可停。从阅读器「润色」进入会自动载入该笔记并带到对应页。从手稿或写作进入会带 `?ms=`，自动载入正文，写回后可回同一篇手稿（载入不等于写回，须再选写回方式）。拓展「相关工作」会叠网址方向或手稿已挂方向的关键词（父方向含子课题）；术语仍是全实验室。拓展「相关工作」并写回手稿时写入「相关工作」节（即使用「文末追加」也会写到该节），并点名已选文献；成功条可写已点名几篇核心文献，并给出下一步（去复现 / 写到核心文献）。写回成功用绿色结果条说明文末追加、追加到哪一节或替换了哪一段，并带版本；下一步单独一行。写回目标与载入分开。作为新笔记写回时会绑定当前页。写回笔记后可回阅读器对应页的笔记栏（仍是文献阅读器，不是独立笔记页）。方法卡若只有摘要或含无依据摘录会标明；再分析不会用弱卡盖掉更好的卡。
- **成员**：导师可调整角色、撤销邀请、移出成员；不能移走实验室最后一位导师。导师可改他人方向（可挂多个，主方向用于文献调研快照）以及在组内 / 休学 / 已毕业。毕业或休学不再算「尚未开读」，仍保留历史归属。点姓名进进度看该成员进展，点方向名进枢纽。「我的」与首页同一套：主方向快照，还可挂其他方向；改主方向不丢掉已挂。按父方向筛成员时看见挂在子课题的人。成员可填写职称或年级（如博二 / 副教授），权限仍只有导师与学生两档。
- **文献调研**：提交研究问题与数据集路径。详情页显示阶段进度、SSE 快照（连接会保持心跳）、工件下载，以及本次写入作业根目录与 `workspace/` 的组内文献 / 数据集（不改引擎图）；问题会要求引用已关联标题，未用须写明。注入文献标题回到你上次读到的页。引擎正常结束记为完成，不会显示成崩溃。问题或关联文献需要实验算力而实验室未开时会等待，不会伪造结果。可暂停 / 恢复 / 取消。网址带 `unused=1` 只看未点名，页头写出是谁、哪个方向，创建折到下面；再带 `direction_id` / `requester_id` 只看该范围，没有时写筛选空，不要假装实验室还没有任务。关掉未点名筛选会一并清掉范围。打开综述没写到会丢掉状态，打开状态会丢掉综述没写到，避免筛成空。按等待算力 / 已入队 / 失败 / 已暂停 / 缺数据筛选也会改页头，没有时写对应空态，创建仍留在上面。按数据集筛选空写「该数据集没有文献调研」。创建时没记下方向的旧任务，不会因为换向算进现方向。周报、统计、研究方向与成员进展上的未点名题名是可点芯片，不是排名。列表下一步先写题名再写篇数。未配个人模型时失败原因可读，并链到个人模型页。
- **复现**：从文献或数据集发起。未填论文声称时会从最好方法卡填入，并标明来源，不会当成实测。缺数据会停住；需要实验算力而管理员关闭时会等待，不会伪造顶会数字。「改进一轮」会带上上一轮诊断再实现，不是从头读论文。列表可按状态、诚实状态、文献、数据集或方向筛选（父方向含子课题，无效方向是筛选空）；从统计或漏斗点「还没做复现」会带上该方向。这些筛选会改页头，没有时写对应空态，不要假装实验室还没有复现。该文献已有任务、只是当前筛选不对时，会写「该文献没有失败的复现」，不是「还没有复现」。有筛选时创建折到下面。详情页同样订阅 SSE。
- **看板 / 组会 / 资料 / 工作日志**：纪要里以「行动:」开头的行会变成任务，可点回该行；任务也能跳回纪要。同一条行动再次提取不会重复建任务。组会列表能看到行动条数。学生只看到自己创建或被指派的任务；未指派的可在「待认领」里认领。资料库同名文件会升版本。工作日志自愿填写，不是监控。顶栏可搜到资料文件名与日志正文并落到高亮行。

## 通知

站内通知带深链，可一键已读。邀请默认尝试发邮件；未配置 SMTP 时页面会提示「已复制链接」。企业微信在后续版本。

## 个人资料与个人模型

在「我的资料」可改显示名与密码（至少 8 位，须含字母和数字）。页脚标注产品版本与 powered by OpenLens。

在「个人模型」先选服务商（地址和对话模型会自动带出），再贴密钥。可选看图 / 向量 / 重排序收在进阶。保存后只显示后四位。可点「测通已保存的配置」：失败会标明密钥 / 额度 / 模型服务，不会显示成成功。未填则回落到实验室或平台默认。实验室模型仅导师可改，不能改实验算力。文献入库不需要模型密钥。

## 手测剧本（学生 / 导师）

1. 选方向 → 首页「打开本方向文献」网址带 `direction_id`。
2. 文献库切换「已发表手稿引用」过滤，刷新后筛选仍在。
3. 阅读器生成方法卡后再提问辅导：方法卡仍在，侧栏出现近期辅导。
4. 写作页对已选手稿点「导师式批注」：本页出现评论列表，手稿侧栏同步。
5. 手稿改为已发表 →「加入文献库 / 知识库」→ 打开新文献条目；再点一次仍进入同一条目。
6. 进度点学生卡：时间线可翻页（事件超过一页时）。
7. 知识库在未配向量模型时提问或综述：即使没有命中，也提示简易检索。
8. 阅读器连问两句：第二句仍在同一辅导会话（网址出现 `session=`，不新开聊天页）。点「新会话」后再问，历史与上一会话分开。无依据回答可「填入下一问」或「重新回答」；`[p.N]` 点回 PDF。
9. 手稿加入引用且正文写上 citation key 或 `\cite{key}` → 侧栏主张追踪显示「正文已点名」；删掉 key 后变为「未点名」。无方法卡时能点「去生成」。
10. 文献库对比两篇 → 导师写入方向说明 / 学生写入手稿「文献对比与差距」。导师再点一次写入，方向说明不重复粘贴同一段。
11. 真复现列表按状态、文献或数据集筛选，网址带查询参数。
12. 文献库「按方向推荐」：未挂该方向但题录相关的已入库篇目出现在「组内相关」，点「挂到本方向」后进入未读列表。
13. 手稿加一条未在正文出现的引用 → 模拟评审评论提到该 key；再点一次评审，评论条数不变。
14. 同一 arXiv（含版本号）或同一 DOI（大小写不同）再次入库：提示库中已有，不新增条目。
15. 把一篇标成想读、另一篇标成在读：进度 / 统计 / 方向抽屉的「在读」只计正在读；周报顶部可点进「按方向推荐」。
16. 阅读器连问超过一页辅导后点「更早的辅导」仍在同一 session；文献库点正在读的篇目打开上次页码。成员进展页「正在读」不含已读。
17. 手稿主张追踪点一条主张：阅读器打开对应页并出现「回手稿」。写作页章节引用卡片显示在读百分比，点进同一页后仍能回手稿。
18. 把一篇读到第 3 页后：点周报或图谱该文献、方向抽屉标题、对比卡「来源」，都应打开第 3 页而不是封面。
19. 从手稿点「去语言工作台」应自动载入正文；选「文末追加」运行后，「回手稿」回到同一篇且正文含润色结果，页上写明「文末追加（版本 n）」。未选手稿写回方式时不得改库。
20. 顶栏输入题名应能跳到已有文献 / 手稿 / 看板任务。方向抽屉可记下开题节点并在手稿页看到。文献调研详情应列出关联的组内文献与数据集说明。
21. 组会「行动:」生成任务后，打开纪要应能点该行进看板，看板任务能回跳同一行。
22. 在成员页填写自己的职称或年级，进度卡片与方向抽屉应能看见；不能因此多出第三种权限。
23. 写作页点一条批注，应打开手稿并滚到该评论。
24. 导师批注后，学生点铃铛应进同一条评论。顶栏也能跳到方向 / 组会 / 数据集。
25. 方向抽屉记下开题并挂手稿后，归属学生应收到通知并落到该研究方向；学生可把节点改成进行中。
26. 对一篇已有方法卡（含指标）的文献发起复现且不填声称：详情「论文声称」应出现方法卡里的指标，且标明来自方法卡；实测仍为空。
27. 把一篇读到第 4 页后发起文献调研并关联该篇：详情注入列表应打开第 4 页。
28. 方向抽屉记下带截止日期的开题后，学生首页「待处理」应出现该节点；导师进度能看见全组节点。把一条复现停在等 GPU 后，首页应能点进 `?status=awaiting_gpu`。
29. 手稿加入引用后，主张追踪应出现「去复现」；对该文献跑过复现后变为「查看复现」。
30. 文献库对比所选后，每篇应有「去复现」。登记数据集时填写说明，列表应显示说明与被任务引用次数。
31. 空实验室打开首页不应看到「等 GPU 0」空卡；记下过期开题后应看到「已过期」而不是一长串时间。
32. 从对比或阅读器点「去复现 / 发起复现」，创建表应预选该文献。点数据集用量应打开已筛的复现或文献调研列表。
33. 带 `?note=` 打开阅读器应先看到笔记栏，当前页笔记在最上面；带 `?session=` 应先看到辅导栏。切到方法卡后网址出现 `panel=card`。
34. 写作页改选题后网址带 `?lit=`；已选文献芯片能回上次页，并能「去复现」。章节引用同样可去复现。
35. 语言工作台写回笔记后，成功条应打开阅读器笔记栏；写回手稿仍回同一篇手稿。
36. 带 `?comment=` 打开手稿应先看到评论栏；切到主张后网址出现 `tab=claims`。
37. 知识库问答或综述后应落到问答栏，引用能回上次页并能「去复现」。
38. 方向抽屉或图谱点一篇文献，应能「去复现」进该文献的复现列表。
39. 首页最近阅读与进度学生在读应有「去复现」；导师点开应落到该生上次页。手稿行可「去写作」。
40. 文献调研列表或详情注入的文献应能「去复现」。周报里入库/在读事件也可去复现。
41. 文献库主表或推荐「本方向未读」应能回上次页并「去复现」。
42. 文献入库通知应能「去复现」；手稿评论通知仍进同一条 `?comment=`。
43. 统计页点方向应进枢纽或本方向文献/手稿；点成员应进进度成员进展。手稿列表可「去写作」。
44. 首页被指派的组会任务应能「回纪要」落到该行。
45. 数据集详情的关联文献应能「去复现」；用量行进现有任务。
46. 手稿保存冲突后应能刷新当前稿，而不是只看见一句报错。
47. 成员页点姓名应进进度该成员进展；有方向时应能点进枢纽。
48. 顶栏铃铛里的文献通知应能「去复现」，与全部通知页同一条。
49. 顶栏输入资料文件名或日志正文应落到对应 `?open=` 行。
50. 关联文献后发起文献调研：工件里应有 `workspace/lab_context.json`，问题旁注含该文献标题。
51. 文献调研引擎正常退出后任务应为已完成，而不是失败崩溃。
52. 复现点「改进一轮」后阶段应是改进/对照/诊断，而不是重新「读取论文」；实测不得等于论文声称。
53. 无 PDF 或仅摘要方法卡应提示先上传可复制 PDF 再分析，不要以为分析坏了。
54. 文献调研详情子图进度应随作业 `states` 文件前进，而不是一直停在第一步。
55. 统计页点「本月开始阅读 / 在投 / 知识库问答」应进文献在读、手稿在投或知识库；点年份应进该年文献。
56. 未指派任务应出现在看板「待认领」；首页或进度「待处理」可点进同一过滤。学生可认领。
57. 问题含 GPU/CUDA 且管理员未开 GPU 时，文献调研应为等待 GPU，而不是模型/容器失败。
58. 数据集列表应能看见文献调研/复现次数和关联文献标题，点次数进已筛任务列表。
59. 对无 PDF 文献发起复现，详情应提示先上传可复制 PDF，并能回到该篇阅读器。
60. 文献调研停在等待 GPU 后点「恢复」：GPU 仍关应再次等待，不得出现成功指标；管理员开启 GPU 后再恢复才能继续。
61. 管理员把 GPU 从 off 改为 internal/external 后，等待中的文献调研/复现应回到排队，管理页能看见等待或已释放计数。
62. 文献库主表应能看出哪篇没有可复制 PDF，并可筛「无全文」、点进阅读器方法卡栏。
63. 首页最近阅读、推荐未读、进度在读预览对无 PDF 篇目应能点「无全文」进阅读器方法卡栏。
64. 复现列表对无 PDF 任务应能看见引导并回到该篇阅读器，不必先打开详情。
65. 文献调研因 GPU 关闭而等待时，进度动态应为「等 GPU」，不要写成失败。
