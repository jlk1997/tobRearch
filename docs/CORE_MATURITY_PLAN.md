# 蜂算科研：核心主路径成熟合同（C 系列）

> 给 coding agent 与人类共同维护。产品名 **蜂算科研**。
>
> **本文件是 G347 之后、针对读 / 析 / 进度 / 方向 / 拓展的施工合同。** 不重写 `docs/PLATFORM_UPGRADE_PLAN.md`、`docs/WORLDCLASS_ROADMAP.md`、`docs/AGENT_ERA_PLAN.md`。G 系列口径陷阱与事件归属十条仍有效。

## 0. 已锁定

| 编号 | 规则 |
| --- | --- |
| D-KEEPAPI | 现有 `/api/v1` 只加字段与子路径。禁止 `/v2`、禁止 `analyze2`。提炼方法仍是 `POST /literature/{id}/analyze`。 |
| D-KEEPTABLE | 不新建 literature / manuscript / authors 影子表。长文提炼进度写在现有 `literature_analyses.result_json`。 |
| D-KEEPUI | 不新增侧栏分组。禁止 `/pi` `/atlas` `/tutor` `/translate` `/degree`、作者产品页。 |
| D-HONEST | 扫描件 `unusable`；弱卡不盖好卡；无正文不假装译/问/提炼成功；驾驶舱动态仍全实验室。 |
| D-NOFORK | 进度加深走 cockpit / stats / digest；推荐加深走文献库 `?tab=recommend`；图谱加深走现有 citation-graph。 |
| D-SEQ | C0 → C239 已闭合（检索合并预印本、阅读习惯只留本人档案）。下一刀 C240 以后。前一波验收不过不铺下一波。 |

**禁止：** 企微、ASR、H6、官方查重、排行红灯、LLM 周报代替可复算数字、给驾驶舱硬加方向、给 `datasets` 加 `direction_id`、改 `build_graph.py` 边语义、第四写作 Agent、Sci-Hub / LibGen / Anna's Archive。

从 C153 起：谷歌学术是助手的默认来源之一。配了 SerpApi 密钥就先走接口；没有密钥或接口失败时，再用海外代理直抓并限速。检索和搜查优先用模型自带的联网，博查和 Tavily 只在原生联网失败时兜底。知网、万方、维普要题录、摘要、关键词和被引；中文开放全文可以直接取；订阅全文走用户自己的文献捕手。对话里可以列出外部领域的代表学者，但要写明口径、不落库、不做页面。组内成员仍然不排名。网上身份要本人或导师确认后才写入档案，只收公开学术信息。学生仍然看不到同学的提问、用量和被指派的任务。

- **C190** 问方向要文章时，用英文术语同时查经典、近期、综述和中文综述。去掉专利、镜像站和新闻。回答按「入门综述 / 奠基经典 / 近两年代表 / 中文综述」分组，每篇带年份、刊物和一句摘自摘要的为什么读。对不上的来源收进「查过但没采用」。
- **C191** 问任何一位外面的人、任何一个方向，都用同一道证据门，不按单个人或单个词表特例。公开网页必须同时对上名字和问句里的单位；知网、学术库题录只要名字按边界对上。方向回答不再把对不上主题的网页写进正文。外面的论文再加 Crossref，计算机方向加 DBLP 和 OpenReview，生物医学加 Europe PMC。没分开综述时直接说明。
- **C192** 问方向时，谷歌学术、知网和公开网页改在同一次并行检索里完成，不再在后面再各查一轮。单次外部请求最多等 8 秒。对话往下长时不再每出一个字就重绘整页。
- **C193** 「某人这个作者/这个老师有什么文章」认成要查的人，走公开学术库，不先停在组内署名。组内没对上时，模型点的认作者也会接着查公开库。内部那句「不要凭名字猜作者」不再当成回答。
- **C194** 「是 S3」「上面这个」沿用上一轮那条出处里的人和学校，不再把同名的人重新摊开。问句里已经写了人名时，不用句末的「他」去换上一轮的人。秦川不算秦川丽或梁秦川，江李铠不算李铠江。中文问句若被写成英文，先退回中文检索笔记，不整段换成「写成了英文说明」。
- **C195** 「大学 人名」这种词序也能抽出人和学校。教师主页上的「秦川导师」「秦川教授」算这个人，不再因后面跟着职称就丢掉。认人时同时查学校官网、中文姓名加单位的谷歌学术，以及「人名 学校 教授」的公开网页。
- **C196** 大模型的 JSON 不再被思考过程或代码块吃掉。MiniMax 的推理进单独字段。流式回答在思考标签没闭合前不往外吐字。解析失败会再要一次，并记一条追踪。
- **C197** 问句先交给模型理解：要找谁、哪所学校、什么主题、上一轮的 S 几，以及各渠道的检索词。人名和单位必须在这一问、最近对话或上一轮出处里出现过。整句问话、校名、成果这类不再当成人名。模型没接上时才用原来的规则。
- **C198** 认人和问方向按模型给的检索词去查 OpenAlex、谷歌学术、学校官网、知网和公开网页。对上之后读学校主页，并取这个作者在该校的作品。第一轮没核上，模型可以换最多三个词再查一轮。
- **C199** 模型核对全部候选，不能只看拿不准的。判「是」必须引用这条原文，而且原文里要有这个人的名字。名字一种写法都没出现的，仍然直接排除。主页上的职称、方向、项目也要能在原文里找到。
- **C200** 问人和问方向的回答由模型按证据来写。出处编号、还不是这个组的成员、还没放进这个组这些话要留下。写出证据里没有的人，或编了不存在的出处，就退回原来的检索笔记。方向回答可以补一句先读哪篇、再读哪篇。
- **C201** 上面几条有测试：JSON 抽取、思考过程不泄漏、编造的人名丢掉、整句不能当人名、没有原文就不能判成是。
- **C202** 已经核对过的论文，署名是英文也算这个人的，写进回答。主页上抽出的研究方向写进开头。同一轮里查过的渠道不再各查一遍。模型按证据写的答案可以只引用用到的编号，不必把笔记里的每个编号再抄一遍。
- **C203** 知网作者页、学者主页不再写成论文。名字对不上的文章不写进正文，只留在查过但没采用。公开网页只要同时写了人名和单位就留下，并引用页面里的原话。名单和公示只说明名字出现在那份名单里，不当成他的研究方向。网页和论文分开列。

## 3. 接棒

交互对照 `docs/UI.md` C1–C239 条。前沿 G 系列已闭合，见 `docs/FRONTIER_MATURITY_PLAN.md` 指针。C240 以后仍只升级现有 endpoint / 表 / 页，禁止平行实现。

C204–C214：组外文献能按 DOI / OpenAlex / 开放 PDF 收进现有文献库；作者作品报公开库总数并给短名单，下一批会翻页，同一页会缓存在现有文件缓存里；组外问题不把实验室方向写进正文；理解层记下综述、经典、前沿和收进组里；答完在现有问答栏追问下一步；「谁引用了这篇」走现有论文环境，接着可以问这篇作者还写过什么。点选的追问以原句为准，不会被改成看书目。一次先收十篇，短名单超过十篇才出现再收一批。中文条目带上知网文件号。有 Semantic Scholar 密钥才补引用，没有密钥就空着。不新开页面。

C215–C218：把「源挂了」和「确实没有」分开。博查、Tavily、OpenAlex、Google Scholar、知网、学术源任一失败都会记进本轮的源失败表，检索工具的 note、认人没核上的话、以及平台空结果的「下一步」都会如实写明哪个源没连上；OpenAlex 限流时不再说「外面没有对上这一篇」，而是说还在退避、稍后再问。失败的空结果不写进检索缓存，免得一整天的检索被一次故障带偏。中文检索改成四个站点按同一预算并行，总量不再由循环顺序决定谁拿得到。报数改成「合并去重后对得上 N 篇，来自哪几个源」，不再用 OpenAlex 过滤前的 meta.count；全面检索的 found 记截断前条数。模型筛掉的部分会写「还有几篇没选上」。书籍章节、百科、学位论文不再当论文呈现；题录带撤回标记。相关论文接口按 OpenAlex 的 related_works 字典解析，OpenAlex 的空字段不再让整个工具报错。

C219–C221：长论文先出一张快卡（摘要、引言和方法开头，大约八千字），侧栏写「快卡」，方法和实验段再用各自的数据库会话并行补上；不超过三段的短论文整篇读完，覆盖说明写「整篇读完」。中文主题的英文检索词优先用理解层给出的英文，其次本组术语表，最后内置小词表；中文相关性改用双字片段，不再因为没有拉丁词就把整批丢掉。理解结果的缓存键带上用户、实验室和会话记忆，避免把别人推出来的名字回给下一个人。推断句和摘要里凭空出现的人名会丢掉。同名、单位没说清、主题太宽才停下来问，其余情况照常回答，并写一句「我按……理解的」。

C222–C224：辅导问的不是「这一页」时，会先在这一篇正文和知识库片段里找带页码的摘录。预印本和正式版在题名、第一作者相同且年份相差不超过一年时并成一条，优先留正式版 DOI。题名规范化走同一套规则，太短的题名用作者和年份做键。用户要最新或给了年份时，OpenAlex 按发表日期而不是被引。检索计划写在答案上方的步骤里：分几步、每步查什么、为什么。依据不足的句子会标明有几句没核上。

C225–C227：章节结构带上已有的精读笔记。可以按节名或页范围取整节，章节旁有「讲这一节」。全面检索顺着「谁引用了它」和「它引用了谁」各走一层，被多颗种子共同引用的标成奠基作，并写明走了几层、多少种子、去重后新增多少。理解层记下目的（入门、找基线、写相关工作、找数据或代码、复现、选题、跟最新、查人），回答和追问芯片按这个目的来。

C228–C230：图表可以「讲这张图」，选中的式子可以「讲这个公式」。没有看图像时，回答写明是按图注和正文讲的。全面检索筛完后给出简报：主线和代表作、按年的时间线、带出处的开放问题、组里已经有的、哪些源没连上。组外问答会按本人最近的检索和在读设默认年份，并写明「按你最近常查的……」，每次可以点「这次不按习惯」。习惯只从本人记录推导，缓存在现有文件缓存里，不进组内页面。

C231–C233：阅读器引用栏可以和组里已有的一篇对比，也可以问这篇的上下游。点答案里的出处会跳到那一页，并说明这一页对没对上那句摘录。论文环境会带上对得上的代码仓库和 Hugging Face 论文页。助手短名单可以导出 BibTeX，组里已有的篇可以全部放进本人的待读。导师可以在方向上写一条阅读路线，刷新前沿时这条路线还在。「下一步读什么」对照本人待读和这条路线来答。

C234：成员卡点写明缺的是哪一类证据，并带上相关文献。还没开读的，列出还没有在读记录的篇，并标明其中哪些还没有方法卡。相关工作和核心文献没写进正文的，列出缺的篇和已有的方法卡一句话。同学打开进度或成员页时看不到别人的卡点。统计里的成员对照表只给导师看。导师可以把一条卡点转成现有的文献调研，问题里写着要补的证据和文献，不另开任务系统。

C235：方向上的「谁还没做完」同样写明缺哪几篇、缺的是还没人在读、没有方法卡，还是没写进正文，导师可以转成文献调研。问「卡在哪、缺哪类证据」时，助手按本人或（仅导师）被点名的成员列出这些文献；学生问同学会被告知不在这里。导师在方向页记下阅读路线，一行一条。点答案里的出处时，对得上的那句会标在 PDF 原文上；对不上就只说明跳到了这一页，不另画一块。

C236：精读这篇时，如果答完仍有句子对不上出处，会先在这一篇里再查一次，把对上的页补进答案；仍然对不上才写「有几句依据不足」。引用栏可以点「找代码」，对上的仓库和 Hugging Face 页写进这篇已有的外部编号，下次打开还在。全面检索会把预印本和正式版并成一条，并写明并掉了几条。方向卡住转成文献调研时，只带文献编号，不会把手稿编号当成文献。

C237：导师可以按外面的前沿和组里还没读、还没写方法的篇草拟阅读路线。综述放进门，经典放进阶，近两年放前沿。草拟不直接写上，确认后仍用原来的「记下」。问「下一步读什么」会跳过已经读完的，指出路线上还没读或正在读的下一篇。方向页写明这几篇发在哪些刊物，并说明只是投稿去向，不是排名。

C238：方向页标出你自己在路线上的进度：已读完、在读、还没读。不看别人读到哪。导师还没记下路线时，按外面已有的前沿草拟下一篇，并写明不是任务。问「下一步读什么」也是这个口径。

C239：文献库检索和全面检索一样，会把题名、第一作者相同且年份相近的预印本和正式版并成一条，留下正式版，并写明并掉了几条。阅读习惯写进成员已有的学术档案里，只给本人的组外检索用；打开档案、成员页看不到这段习惯。最近没有新检索时，仍用上次记下的习惯，不假装刚了解他。
