# 蜂算科研管理员手册

面向机构管理员与实验室导师。产品名：**蜂算科研**。

## 首次上线

1. 按 [部署手册](DEPLOY.md) 启动 API 与前端。
2. 用管理员邮箱登录（环境变量 `ADMIN_EMAIL` / `ADMIN_PASSWORD`，未设时默认 `admin@example.com` / `changeme1`）。立即修改默认密码（至少 8 位，须含字母和数字）。管理员登录后进入「管理」页。
3. 管理页分三块：先在「开通」处理**机构申请**（通过则建空实验室并把申请人设为导师；驳回须填原因）。页头清单会标出待审数。
4. 在「模型与算力」核对实验算力。选项为关闭 / 实验室集群 / 外接集群。无集群时保持「关闭」，禁止伪造指标。
5. 同一栏配置平台模型：选服务商后贴密钥、保存、测通。文献检索不走这项。不要把模型地址填进实验算力。

## 邀请与角色

- **开通机构**走公开申请 + 运营审批；**加入实验室**仍须持有效邀请。导师在「成员」页按邮箱邀请，角色为 `teacher` 或 `student`。职称/年级只是展示字段，不增加权限档。
- 已开通机构的导师可在本机构再建空实验室（仍禁止写进其他机构）。
- 加入即同意组内透明：成员可看彼此在读文献、进度与手稿正文；仅作者可改正文。
- 可删除出厂「引导实验室」。真实实验室默认空库。

## 手测剧本（机构开通）

1. 未登录打开 `/apply` 提交申请 → 用同一邮箱登录 → 落在 `/pending`，侧栏无文献 / 手稿。
2. 管理员 `/admin` 看到待审 → 通过 → 申请人刷新后 `workbench_ready`，成员页可发邀请。
3. 驳回须填原因 → 申请人在开通进度看到原因 → 改说明重新提交回到待审。
4. 学生走邀请链接注册后 `org_id` 与实验室机构一致。同机构第二间实验室对已有账号应走「登录并加入」。
5. 停用机构后成员进开通进度、无法发邀请；深链打开文献等 API 亦 403；恢复后可再进工作台。
6. 新申请应在管理员通知铃铛出现「新的机构开通申请」，侧栏「管理」显示待审数；通过后跳到该实验室成员页。
7. 邀请已归属其他机构的邮箱应明确失败，而不是发出无效邀请。
8. 同名机构（待审或已开通）不可重复申请。
9. 机构停用后，旧邀请链接预览为「机构暂不可加入」；恢复后开通进度页轮询应能自动解锁工作台。
10. 若申请人已开通却进不了工作台，管理页再点「修复」应补建实验室；`me.workbench_block=no_membership`。
11. 停用期间导师仍可进成员页撤销未用邀请，但不能新发；用户表可按机构状态筛，审计可选「机构相关」。
12. 已驳回不可直接「通过」，须申请人重提后再批；恢复开通后跳到成员页。

## 驾驶舱

三次点击应能看到学生在读与手稿正文：驾驶舱 → 成员卡片 → 学生时间线；从「成员」表点姓名同样进该生成员进展。卡片含可复算的在读进度（仅正在读，想读另计）、方法卡数、手稿停留、等 GPU / 缺数据。数字与「统计」页、数据库一致时可导出 CSV。点方向行进入方向枢纽，不要寻找 `/atlas`。周报可深链到文献库推荐 Tab。

## 密钥与配额

- 解析顺序：用户 → 实验室 → 平台默认。`kind=onprem` 时 `base_url` 指向内网网关即可，chat / vision / embed / rerank 共用该 URL、按模型名分流。
- 「测通」在测试环境校验解密；生产请求兼容接口的 `/models`。失败须分类可读（权限 / 额度 / 模型服务），`ok:false` 不得显示成成功。管理页可测平台默认 Key。
- 知识库索引优先调用凭据 embedding；CI / 失败时 hash 回退并在问答结果标明 `embed_fallback=hash`（无命中时横幅仍在）。
- 重型任务（发现式 / 复现）受每用户 / 每实验室槽位与月 token 预算限制。暂停与等待 GPU 仍占槽。超限返回 429。Worker 抢单执行，避免与 API 双跑。复现方法卡只来自文献分析，无分析则诚实失败，不得用启发式冒充成功。声称与实测分列，轮次日志可见。

## 手测剧本（管理员 / 导师）

1. 管理页保存平台 Key（可标内网）→ 测通；故意填错应看到分类错误，不是成功 toast。
2. 驾驶舱卡片数字与统计页、CSV 对得上；点成员时间线翻页。网格前「待处理」只在有未完成节点或等 GPU / 缺数据时出现。成员页在读 / 想读 / 已读分列，点标题带上次页码。动态流断开后可重连。
3. 方向抽屉：文献 / 组内相关推荐 / 手稿 / 图谱链接都带 `direction_id`；成员可进时间线。在读人数不含想读。
4. 已发表手稿加入文献库后，文献库用「已发表手稿引用」能筛到被引用篇目。
5. GPU 保持 `off` 时复现停在 `awaiting_gpu`，详情不出现伪造指标。未填声称时从方法卡填入的数字仍标成「论文声称」，不得出现在实测卡。
6. 对比结果写入方向说明后，方向抽屉能看到「文献对比与差距」；再写一次同一段不会重复。
7. 复现列表 `?status=awaiting_gpu` 只留下等 GPU 的任务；`?dataset_id=` 只留下该数据集。
8. 统计 CSV 的方向行「在读」与驾驶舱一致；另有想读列。周报页能打开 `?tab=recommend`。
9. 打开学生手稿主张追踪，点主张应落到阅读器对应页；工具条「回手稿」回到同一篇。写作引用卡片能看到该生在读百分比。
10. 学生读到第 3 页后，导师从周报 / 图谱 / 方向抽屉点该篇，应落到该导师自己的上次页（若未读过则方法卡页或第 1 页）；成员「正在读」列表仍显示学生进度页。
11. 学生在第 5 页写笔记或从语言工作台写回笔记后，周报 / 通知应进阅读器第 5 页并高亮该笔记；阅读器「润色」应自动载入笔记正文，写回后能回同一页。
12. 从学生手稿去语言工作台润色并文末追加后，应能点「回手稿」回到同一篇，并看到「文末追加（版本 n）」；未选写回方式不得改正文。
13. 顶栏能跳到组内文献 / 手稿 / 任务。方向抽屉可记下开题（含截止日期）并在学生手稿与首页「待处理」看到。发现式详情列出注入的组内文献/数据集且带上次页，且不假装改了引擎图。
14. 完整实验室用 Compose 的 Postgres 16 + pgvector；本机 SQLite 仅单人开发。可选 `REDIS_URL`，抢单语义仍是 `claim_next`。
15. `GET /health` 应带回 `X-Request-Id`、产品版本 `0.2.0` 与 `worker`（last tick / lag）。第二个 worker 进程抢不到 `worker.lock` 时不应双跑。捕手选项页可用实验室账号登录，不要另发扩展。管理页用量表有时间，并展示同一套工人快照。
16. 写作页选题芯片与章节引用都能回该生上次页，并可落到复现列表。语言写回笔记的成功条应打开阅读器笔记栏，而不是新笔记产品。
17. 手稿 `?comment=` 应先开评论栏。知识库问答引用与方向抽屉文献都能落到复现列表，不要另开图谱或批注产品。
18. 驾驶舱点学生在读「去复现」应落到该生上次页，不是导师自己的进度。发现式注入与周报文献事件同样进现有复现列表。
19. 文献库主表 / 推荐已入库行、通知与统计方向/成员都应落到现有对象，不要另开检索或统计台。手稿评论深链仍是 `?comment=`。
20. 首页组会指派应回纪要行。数据集关联文献进复现列表。手稿 409 应带回跳，不要做成选区锁。
21. 成员表点姓名进驾驶舱该生进展。顶栏铃铛文献通知可去复现。顶栏能搜到资料与工作日志。
22. 发现式正常跑完应记完成，不因引擎 `sys.exit(0)` 变失败。关联文献后作业 `workspace/` 里有 `lab_context.json`。复现「改进一轮」带诊断，不得把声称写入实测。
23. `GET /health` 应含 `db.ok`；未配 Redis 时 `redis.configured=false`。Compose 中 api 应等 Postgres ready。CI 须 `web_next` 构建通过。本地可选 `FENGSUN_NIGHTLY=1` 验证工人 stub 收尾；`FENGSUN_E2E=1` 跑 Playwright 烟尘。
24. GPU 为 off 时，发现式含 CUDA 的问题应停在 `awaiting_gpu`，不得写成成功指标。复现队列「等 GPU」计数仍只计复现；发现式另有 `research_awaiting_*`。
25. 管理页 GPU 栏应显示发现式/复现等待数。改为 internal/external 后这些任务应重新入队（`released_*`），不得在本页伪造指标或新开监控台。
26. 学生任务停在等待 GPU 时，导师驾驶舱动态应出现「发现式等 GPU」或「复现等 GPU」，深链进该任务，不得显示成失败。
27. 学生自己也应在铃铛看到「等 GPU」（不发邮件）。点动态进该任务。管理页开启 GPU 后仍走恢复/重新排队，不在本页伪造指标。
28. 管理页 GPU 栏应列出等待中的发现式/复现任务名并可点进详情。改为 internal/external 后列表应清空（`released_*`），不得新开监控台或伪造指标。
29. 开启 GPU 后，发起学生铃铛应出现「已入队」（不发邮件）。统计页等 GPU 数字可点进已筛列表，不是新监控台。
30. 本机或测试未开工人时，开启 GPU 只重新入队、不在管理页开跑。学生点「恢复」才当场执行。等 GPU 计数与复现 href 口径不得改成混计发现式。
31. 开启 GPU 后 `waiting` 应清空；若工人未开，同栏应另列「已入队」任务并可恢复。不要把这些行写进等 GPU 列表。用量/探活应写明工人未开。
32. 管理页或学生点「恢复」后，提示必须跟返回的 `feedback`：GPU 仍关是警告，当场跑完是成功。不得一律「已请求恢复」，不得伪造指标。等 GPU 计数/href 口径不变。
33. 开启 GPU 后提示必须跟 `feedback`：工人未开应警告「已重新入队，学生需点恢复」，不得一律成功「已重新排队」并假装在跑。PUT 仍只入队、不当场全跑。学生撞额度应看到下一步，不是只报 429。
34. 开启 GPU 后学生详情/流不得再念旧的「等 GPU」诊断。运行中或已跑完的任务被恢复应 409，不得被打回队列。等 GPU 点暂停不得报「已结束」。
35. 成员进展必须列出 queued。学生把已结束任务再恢复/改进时若槽位已满应 429，不得叠两条重型任务。已取消的复现不得被改进一轮复活。
36. 连点恢复/改进不得双开同一作业。额度数字口径不变；多进程 SQLite 也不得两人同时抢到同一实验室槽。空闲 SSE 可少读盘，但快照仍带反馈。
37. 方法卡无依据指标不得灌进复现声称。对比 gap 无文献 id 应被裁空。辅导编造数字须打标，不得当作成熟问答。禁止新开 Agent 台或改发现式图边。
38. 大纲无方法卡须标明「未结合方法卡」。章节/KB 编造数字须打标。图谱用最好卡。推荐标明 `embed_fallback=hash`。token 超限 429 须带预算下一步，不得假装生成成功。等 GPU href 仍只指向复现列表。禁止第三条写作或新 RAG。
39. 发现式缺 `plan.md` / 文献综述，或组内文献既未点名也未标「未使用」，不得标完成。禁止改图边或新开 Agent 台。等 GPU href 口径不变。
40. 复现 stub / 无 Docker / 无 GPU / 非法实测文件应分列 `error_class`，不得一律 docker，也不得把声称写成成功实测。外部 GPU 回调抄声称仍须清空。禁止第三条复现引擎。等 GPU href 口径不变。
41. 驾驶舱/统计应出现复现诚实计数（已实测 / 未跑 / 测试桩）。对比、辅导、大纲、发现式注入应看见同一条证据。禁止排行榜或新开实验台。等 GPU href 口径不变。
42. 图谱 / 方向枢纽 / 主张 / 知识库 / 首页待处理应看见同一条复现证据。发现式 sidecar `reproduce_gaps.md` 不得被当成综述已点名。方向说明「组内复现差距」幂等替换。禁止新产品页、排行榜或改 awaiting href。
43. 周报 / 统计方向行 / 引导应看见同一条复现脊柱。模拟评审与发现式收尾须拦截「未测当成功」。禁止官方查重、排行榜、改图边或改 awaiting href。
44. 手稿保存 / 通知 / 文献与复现列表 / Overleaf zip / 语言工作台应看见同一条复现证据。未测当成功只警告不拦保存。zip 的 `reproduce_gaps.md` 不得写进 `main.tex`。禁止新产品页、排行榜、改 awaiting href 或 Era D。
45. 同一文献后一次失败不得盖掉已有实测。「尚无实测」含缺数据。保存与模拟评审对题名点名同一口径。禁止新产品页、改 awaiting href 或 Era D。
46. Overleaf sidecar / 语言无手稿 / 主张栏 / 驾驶舱与统计 / 周报 / 发现式闸应看见同一条「未测当成功」脊柱。`lab_context.json` 只当证据源，不得当成综述已点名，也不得写进 `main.tex`。禁止新产品页、排行榜、改图边或 Era D。
47. 发现式未点名闸 / 驾驶舱动态与进展 / 方向枢纽 / 图谱 / 引导 / 写作与知识库应看见同一条脊柱。只点名已实测不得误报「尚无实测」。禁止新产品页、改图边、排行榜或 Era D。


## 审计与安全

- 「管理」页可查审计（按动作 / 用户筛选）、用量、用户关停。离开某实验室后管理员仍可进入该实验室驾驶舱。
- 全站 JWT；跨实验室 403；接口限流默认约 180 次/分钟。任务接口不回显服务器路径。排查时用响应头 `X-Request-Id`。
- 浏览器捕手只导入用户主动打开且有权访问的页面。禁止付费墙绕过与 Sci-Hub。

## 备份与故障

- 定期运行 `python scripts/backup.py`。
- 发现式任务失败会给出可读 `error_class`（如 docker / quota / llm）。复现另有 stub / no_docker / no_gpu / parse。工件在跑行详情中下载，路径不会逃出作业目录。
