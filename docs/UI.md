# 蜂算科研 UI / 交互规范

产品是实验室的记忆，不是演示站，也不是聊天机器人皮肤。学生完成一篇论文：方向是墙，文献和论文是两张纸。导师在三次点击内看到这个人这周在读什么、论文写到哪一节。复现是论文里某一句需要实测时才进入的一页，不和学生写论文并列。

本文件是前端实现的对照标准。代码入口：`web_next/src/theme.js`、`web_next/src/nav.js`、`web_next/src/ui.jsx`、`web_next/src/shell.jsx`、`web_next/src/err.js`、`web_next/src/index.css`。产品范围与非目标仍以 `docs/PLATFORM_UPGRADE_PLAN.md` 为准；H2 起加深以 `docs/WORLDCLASS_ROADMAP.md` 为准；读析进度方向拓展以 `docs/CORE_MATURITY_PLAN.md` 为准。禁止 `/atlas`、独立辅导页、第二套 Key 菜单。

## 1. 原则

1. **先定位，再操作。** 任何时候都能回答：我在哪个实验室、哪一类工作、哪一条对象上。导航有选中态，详情页有面包屑，`document.title` 随页变化。
2. **学生一条路，导师仍分组。** 学生侧栏第一项是助手，然后是方向、文献、论文、通知，其余收入「更多」。导师第一层是进度、助手、文献库、论文、成员、方向、通知；文献调研和复现在「更多」。界面按四类页面来：方向是墙，文献是名单，阅读和论文是纸，进度是人。每一页内部可以重排，不新开网址。助手页是一条对话纸面，不算第五类。左侧可以新开、搜索、改名和删除自己的对话；改名只改显示名，不改原来的问句。禁止新增分组，禁止把学生侧栏恢复成五组。顶栏有「问助手」，跳转落到现有详情，不是新搜索页。
3. **纸张与墨，不是霓虹。** 暖纸底、墨绿主色。OpenLens 不出现在主标题，只在页脚与关于。中文字体优先（微软雅黑 / 苹方 / Noto Sans SC），再 Segoe UI。
4. **空态是下一步，不是空白。** 引导清单未完成步骤可点进对应页面。表格空态说明「还没做」以及「去哪做」，并带一个主按钮。
5. **一页一个主操作。** 其余进折叠或次要按钮。页头一行说「这页干什么 + 下一步」。
6. **一能一名。** 复现 / 文献调研 / 个人模型 / 实验室模型 / 平台模型 / 译润；主界面不写 JWT、子图、OpenLens、`awaiting_gpu`、hash 回退原文。
7. **失败可读。** 轻量模型失败用分类标签（解析 / 密钥 / 额度），禁止无限转圈或堆栈。缺模型密钥时链到「个人模型」并写明个人 → 实验室 → 平台。
8. **按钮按角色显示，以后端 403 为准。** 隐藏不是安全边界。
9. **全组都能看见不等于催促。** 工作日志、最后活跃用中性语气，不做排名红灯。
10. **危险需确认。** 删除实验室 / 成员 / 手稿 / 文献用 Popconfirm。不能移除最后一位导师，不能停用最后一位管理员。上传文件名不得带路径。

## 2. 信息架构

登录后壳层：顶栏（品牌、实验室切换、**实验室内跳转**、通知铃铛、用户菜单）+ 可折叠分组侧栏 + 内容（面包屑 + 页面）。跳转框是暖纸底墨绿字，搜文献（题名 / 作者 / DOI / arXiv / 刊物）/ 手稿 / 任务 / 方向 / 组会 / 数据集 / 资料 / 日志 / 文献调研 / 复现并落地现有详情，不是新搜索页。`/` 或 Ctrl+K 聚焦；没有组内对象去文献检索。窄屏默认收起侧栏。

学生默认看见的是一列：助手、方向、文献、论文、通知，加一个「更多」。导师仍按组看见，工作台组里在进度旁边有助手。路由全部保留。顶栏「问助手」在每一页都能打开，带着当前方向或当前人；读论文那一页则打开这篇的辅导。

| 分组 | 全部入口（路由保留） | 学生默认看见 | 导师默认看见 |
| --- | --- | --- | --- |
| 学生主路 | 助手、方向、文献、论文、通知 | 这五项；首页、写作、知识库、译润、文献调研、复现及其余进「更多」 | — |
| 工作台 | 首页、进度、助手 | 助手在主路 | 进度、助手 |
| 科研资产 | 文献库、写作、论文、知识库、译润 | 文献、论文 | 文献库、论文 |
| 实验任务 | 文献调研、复现 | （在「更多」；复现只从论文里那一句进入） | （在「更多」；复现页仍在） |
| 协作 | 成员、方向、看板、组会、资料、统计、日志、数据集、引用图谱、周报 | 方向 | 成员、方向 |
| 账户 | 通知、个人模型、实验室模型、资料、开通进度、管理 | 通知 | 通知；管理始终钉住（管理员） |

只有一个方向时，学生登录后的第一屏就是这个方向。多个方向时，工作台只用来选一个方向。组内未列出的入口收入「更多」。当前路由若在「更多」内，自动展开。深链与书签 URL 不变。

详情路由挂在对应入口的选中态上：`/literature/:id` 点亮「文献」，`/runs/:id` 点亮「文献调研」，`/manuscripts/:id` 点亮「论文」。

命名：复现（按钮：去复现 / 开始复现 / 查看复现）；文献调研；个人模型 / 实验室模型 / 平台模型；译润（页题仍可写「语言工作台」）。等待实验算力不用 `awaiting_gpu`；未接向量模型用「简易检索」，不写 hash。

未登录：登录页、**申请开通页 `/apply`**、邀请页使用 `AuthFrame`（品牌 + 实验室名/角色/条款）。登录页有「先以游客体验」，进入共用的体验实验室；工作台顶部说明后来的人也能看到提问、笔记和上传，并链到申请开通。登录副文案链到申请开通。过期或已用邀请不是空白表单。邀请预览若 `account_exists`，展示登录并加入，而不是再注册。

已登录但机构未开通：落在 `/pending`（开通进度，约 15 秒轮询，含停用恢复）；侧栏只留开通进度 / 通知 / 资料；顶栏隐藏实验室切换，用浅色锁定芯片（禁止深色字叠墨绿底）；`/pending` 用纸色状态卡，不叠两条提示条。访问其他工作台路由重定向到 `/pending`。若 `workbench_block=no_membership`（机构已开通但未加入实验室），文案区分于「审核中」。停用时侧栏额外开放「成员与邀请」以便撤销未用邀请（不可新发）。管理员登录后进 `/admin`，侧栏「管理（待审 N）」；「通过」仅待审，「修复」用于已开通无成员；驳回后须申请人重提；通过/恢复后深链成员页；机构表展示联系人与驳回备注；用户表可按机构状态筛，审计可选「机构相关」。成员页导师可「本机构再建一组」，邀请仅限本机构邮箱且不可重复未用邀请。停用机构的邀请预览显示「机构暂不可加入」，不是空表单。提示条一律浅底深字（info 水绿、warning 暖纸、error 浅红）。

一页最多一个主按钮 `type="primary"`。

## 4. 全局交互

- **三次点击（导师）：** 登录后直接进进度 → 学生卡 → 在读标题或手稿标题。卡片可点，标题 `stopPropagation` 进对象。
- **登录落地：** 管理员 → `/admin`；机构未开通 → `/pending`；导师 → 进度；学生只有一个方向时 → 该方向，否则 → 工作台用来选方向。邀请注册同样按角色落地。
- **通知：** 顶栏铃铛下拉最近 8 条；点标题跳对象并标已读。「全部通知」进列表页。全部已读同步铃铛为 0。动态、时间线、通知共用 `noticeHref`。组会深链为 `/labs/:id/meetings?open=:meetingId`。复现不出现在通知卡的主操作上。
- **会话过期：** refresh 失败回登录，不留半屏转圈。
- **长任务：** SSE 心跳；暂停 / 恢复 / 取消始终可见；页面顶部用一句话说明「此刻在等什么」（`runWaitHint`，优先 `feedback`）。无 GPU 用警告条，不装成功。恢复结果走 `tellFeedback`，禁止一律「已请求恢复」。
- **快捷键：** 手稿作者 `Ctrl/⌘ + S` 保存；未保存离开走 `beforeunload`。跳到内容跳过导航。
- **焦点：** 键盘 `:focus-visible` 可见。提供「跳到内容」跳过导航。
- **列表进详情：** 可点行加 `fs-click-row`。行内危险按钮 `stopPropagation`。
- **上传：** 文献 PDF、资料库、知识库用 Ant Design Upload / Dragger，禁止裸 `input[type=file]` 作为主入口。

| 看板 | `.fs-kanban` 三列，空列有说明 | 任务 |
| 图谱页 | 左邻接/简易 SVG，右对象摘要 | 引用图谱 |

页头一律：标题 + 一句说明 + 可选右侧主操作。不要再用孤立的 `Title level={3}`。列表页创建走页头按钮 + `CreateDialog`；筛选行只放状态 / 方向 / 作者等过滤，禁止放名称、题目、研究问题等填写项。`?compose=1` 打开弹窗，关掉去掉；文献入库沿用 `?tab=search|recommend|manual`。

## 6. 分页面交互

### 认证

登录：邮箱 + 密码，主按钮「进入工作台」。邀请：预拉实验室名与条款，勾选全组都能看见后设密。无效 token 给 Result，不是空表单。

### 工作台 / 进度

四张版式是展示标准。后面各条 F 记的是接口和字段仍然怎么算，不是要把仪表盘装回第一屏。

工作台不是第五张版式。学生只有一个方向时，登录后就是那面墙。多个方向时，工作台只列方向名。导师登录后的第一眼是进度；点品牌也回到进度。工作台若从「更多」打开，第一眼只留接着读和接着写。先看这一件、待处理、没挂方向的说明、最近问过、文献调研留在折叠里。在读行打开上次那一页，下一步是问这篇或提炼方法，不把「去复现」放在行上。空态链到文献或论文。

进度是导师门口。一张卡一个人，先三句可点的话：这周在读哪篇（落到该生上次页）、论文写到哪一节、卡在哪一件。计数、待处理、漏斗留在「数字」或「更多」里。禁止排行红灯。点卡进时间线。复现仍可从「还有」进入，不作为卡面的第一句。

统计页额外展示本月：开始阅读、在投、知识库问答；三卡可点进现有文献（在读）/ 手稿（在投）/ 知识库，与 CSV `this_month` 行一致。`by_year` 展示并点进文献 `?year=`。方向名进枢纽，文献/手稿数列进现有过滤列表；成员名进进度成员进展。工人未开时多两张「已入队」卡进 `?status=pending`，等 GPU 卡口径不变。禁止排行红灯。

**本周概况（F1，现有三页加深，不是新报表）：** 进度 / 统计 / 周报顶部共用 `situation.lines`，六句可复算且可点：人（进进度）、方向（进枢纽）、本周/本月、诚实脊柱、AI 用量、风险（学位过期 / 等 GPU / 还没复现就写成成功 / 已入队）。语气中性，禁止「垫底」「落后」。导师可见 `ai.usage_by_member`（按姓名排，不按 Token 排行）；学生只见实验室合计与自己的用量，`peer_usage_hidden=true`。CSV 同步 `situation` / `ai` / `this_week` 列。成员行可展示 `title`（职称/年级），不参与权限。

**F6 打磨：** 六句计数为 0 时写 `empty_text`（下一步，不是空白）。额度将满用现有警告条 + `quota_next`（联系导师/管理员调预算，不伪造指标）。工人未开且有已入队时，风险句写「工人未开」并点进 `?status=pending`，不把等待写成失败。检索无结果展示 `empty_next`：换 PubMed/Semantic Scholar、捕手 `?tab=manual`、上传 PDF。顶栏跳转找不到实验室对象时复用同一套下一步，跳转本身仍不是学术检索。相关工作写回成功条与译润同一套：摘要 + 打开手稿芯片（`writeback.summary` / `href`）。

**F7 带组导师 / 学生下一步：** 研究方向顶部用现有对象列出 `stuck`（无人在读、无方法卡、未写相关工作、核心文献还没写进正文、还没做复现、还没复现就写成成功、学位过期、尚未开读），数字可点进文献库 / 手稿 / 复现 / 进度，禁止「落后」「垫底」。导师可见尚未开读学生姓名（按姓名排，进成员时间线），学生只见计数。学生首页 `next_steps` 字段仍是全量（测试与导师复算用）；学生首屏只渲染 `next_steps_shown`（最多 2 条，中性措辞）。导师工作台下一步见 F11。写作页选手稿后展示与主张追踪同一套「还没写到 N 篇核心文献」，链到 `?tab=claims`。按方向推荐全空时复用检索 `empty_next`，并多一步「先填方向关键词」。

**F8 指挥面吃卡住：** 进度成员卡与成员进展复用同一套 `stuck.steps`（选定方向、尚未开读、未写相关工作、还没复现就写成成功、学位过期、等 GPU、缺数据），禁止按卡住程度排卡。卡住清单默认折进「需要关注」，展开才出全量与题名芯片。手稿行可标「未写相关工作」。统计方向行增加无人在读 / 未写相关工作 / 还没做完计数并点进枢纽；成员行卡住进时间线。周报与 CSV 增加 `stuck_brief`（「卡住：…不是排名。」）。

**F9 卡住数字落到过滤列表：** 研究方向 / 统计 / 周报的「无人在读」进 `literature?reading_status=unread`（组内没有正在读，不是个人想读）。「无方法卡」进 `?has_card=0`。「未写相关工作」进 `manuscripts?related_work=0`。「核心文献还没写进正文」进 `manuscripts?core_missing=1`（F12）。相关工作只认 Markdown/LaTeX 标题行，正文写「没有相关工作」不算已写。不新增列表页，不按还没做完排序。

**F10 对比写回闭合卡住：** 文献对比主按钮「写回相关工作」走现有 `append_heading` + `describe_writeback`，写入 `## 相关工作`，成功条与译润同一套。只写入「文献对比与差距」仍不算已写相关工作。写回响应带 `related_work_written` / `core_coverage`。方向列表增加卡住 / 无人在读 / 未写相关工作列，数字进现有过滤或枢纽，禁止按卡住排序。

**F11 导师落地页吃卡住 + 对比点名：** 进度与导师工作台复用周报同一套 `stuck_brief`（无人在读 / 未写相关工作 / 还没做复现 / 还没复现就写成成功），数字进现有过滤，禁止排行。导师工作台「组里还没做完」来自该摘要，默认折进「需要关注」，不催导师自己开读。学生首页仍只谈自己，不回传 `stuck_brief`。对比响应增加 `related_work_md`（在 `gap_md` 上盖所选篇目题名），写回相关工作后主张追踪能点名这些核心文献；成功条可写「已点名 N / 共 M 篇」。不是第三条综述。

**F20 成员卡能点进该生 + 建稿后续写：** 进度成员卡 extra 与「在读 N 篇」落到该成员文献（无在读=`reader_id`+`unread`+方向；有在读=`reading`），并给出「该成员手稿」`owner_id`。统计成员行「在读 / 手稿」同一套链接。`POST /manuscripts` 返回 `next_step`「写相关工作」。写作页点「从大纲创建手稿」后切到相关工作标题并换下一步，**不在生成大纲接口里自动建稿**。F9 组内无人在读、学生首页「开始阅读」口径不变。

**G128–G130 筛选诚实 / 互斥 / 数据集页头：** 该文献已有复现、只是当前状态/诚实不对时，空态写「该文献没有失败的复现」，不要写「该文献还没有复现任务」。`queued` 与 `pending` 同一套「已入队」页头。打开综述没写到会丢掉状态，打开状态会丢掉综述没写到；接口未点名时不再被 `status=pending` 筛成空。数据集库空用警告条和页头，复现/文献调研按数据集筛选空写「该数据集没有…」。

文献库页头：「本实验室的论文。没有的先入库。」**主区先出本库表**。空态主按钮「拖入 PDF 或填 DOI」，并写明入库不用模型密钥。页头常驻检索栏（开放源 + 本库）；空库或网址带 `?q=` / `?tab=search` 时默认打开检索并预填。检索结果与推荐共用同一卡片：题名、年、来源、是否已入库、有无 PDF、复现诚实、一键入库、去阅读器/去复现。中文源继续「链接 + 捕手」，不假装知网全文库。顶栏 jump 无组内命中时给出「去文献检索」落到 `?tab=search&q=`，**不把 jump 做成学术搜索**。检索开放源、按方向推荐、BibTeX/CSV、捕手收入「其他入库方式」（`?tab=search|recommend|manual` 深链仍打开对应栏）。捕手改为可选扩展，令牌在扩展选项页填写，不占第一屏。默认检索语言跟界面；来源默认 arXiv + 本库。过滤默认：方向、在读、搜索；年份 / 全文 / 复现状态进「更多筛选」。库表可点行进阅读器（带上次页 `href`），每行可「去复现」；「全文」列标明无 PDF / 扫描件 / 仅摘要并进 `?panel=card`。拖入多个 PDF 默认在读。对比结果用卡片，标题与「来源」链到阅读器上次页或方法卡页；每篇可「去复现」落到现有复现列表 `?literature_item_id=`（优先服务端 `reproduce_href`）。推荐「本方向未读 / 组内相关」同样回上次页并可去复现；已入库行标明无全文并进 `?panel=card`。对比后可将 `gap_md` 写入方向说明（导师）或手稿草稿（作者），禁止当成第三条写论文。过滤写入 URL：`direction_id`、`reading_status`（含 `unread` 无人在读）、`reader_id`（该成员在读状态，叠 `unread` 为该生未开读）、`reading_scope=lab`（组内有人处于该状态的篇目，不是我的在读）、`cited_by_published=1`、`has_pdf=0|1`、`has_card=0|1`、`core=1`、`tab=recommend|manual|search`。手稿列表另有 `related_work=0|1`、`ungrounded=1`、`core_missing=1`。推荐展示外源未入库（arXiv / PubMed / Semantic Scholar / medRxiv / bioRxiv，按组内语料重排，展示匹配词不展示分数；用了模型微调则白话说明，失败保持组内语料序；未接向量则写「简易检索」）、「本方向未读」、以及「组内相关（未挂本方向）」可一键挂上。当前筛选方向时入库会挂该方向。未选方向时外源按全部方向关键词，未读回落到当前成员选定方向。重复入库返回 `already_in_library`，toast 区分「库中已有」与新入。

阅读器对象页：主列 PDF（可「看中文」伴读本页译文；选中即译并带前后文；弹层可问这一句或改措辞；无正文不请求），侧列**在读条始终可见**，其余用 `?panel=card|notes|tutor` 一次只开一块（禁止 `/tutor` 或新阅读产品）。工具条分组：**在读** | **读懂**（这篇怎么做、辅导）| **写**（写作、回手稿）| **跑**（开始复现）；入知识库、下载、删除进「更多」。译润页负责改和写回，不和「译这一页」并列。有最近复现时用现有警告条写下一步并可「恢复」，不另加「去复现」芯片。有 `?note=` 先开笔记栏，有 `?session=` 先开辅导栏，否则方法卡。当前页笔记置顶。**精读辅导**提问走 `POST /literature/:id/tutor`，可带 `session_id` 续聊，写回走现有笔记，不新开聊天页；网址 `?session=` 可分享同一会话，「新会话」另起。侧栏是正序气泡而不是「最新回答 + 灰字历史」。`GET .../detail` 带 `tutor_sessions` 下拉与 `tutor_history`（仅本人本会话，可「更早的辅导」），不得覆盖方法卡；点页码跳 PDF。发送中保留待发送气泡，助手气泡可写笔记或去译润。方法卡摘录须能点回页码；无依据摘录标 `ungrounded`。侧栏方法卡空态用现有警告条区分 `abstract_only` / `ungrounded` / `unusable`，写清下一步「上传可复制 PDF / 再生成方法卡」，不新开分析页。翻页写入进度且不刷屏开始阅读事件。`?page=` 滚 PDF；文献库 / 进度 / 首页链到阅读器时带 `last_page_no`。从手稿主张或写作引用进入时带 `?ms=`，工具条出现「回手稿」，「去写作」保留该手稿。「去译润」带当前 `?page=`；笔记「润色」带 `?lit=` / `?note=` / `?page=` / `?panel=notes`。`?note=` 高亮该笔记，无 `?page=` 时滚到笔记绑定页。作者可改页注。无 PDF、文件缺失、渲染失败分态展示，均指向上传可复制文字版；扫描件 unusable 时提示换可复制 PDF。文献库方向下拉失败可重试，不与「没有方向」混淆。`source_channel=manuscript` 时标明来自已发表手稿。捕手导入重复题录返回 `already_in_library`；知网/IEEE 弱 meta 仍降级，不假装全文库。

写作工作台独立成页：`?lit=` / `?ms=` 预选文献与手稿，改选题或手稿时把同一查询写回网址。已选文献以芯片展示：标题回阅读器上次页，并可「去复现」。界面用步骤条：选题与大纲 → **相关工作** → 章节 → 写回；同时只强调一个主按钮。相关工作须吃最好方法卡、组内复现差距与可点引用；无全文标「仅摘要」。可不选文献，此时用含「相关工作」的骨架并明示未结合文献。选了文献但还没有方法卡时明示未结合方法卡，不新开写作引擎。章节若编造本轮片段没有的数字，用现有警告条标明无依据。大纲失败用页内错误，不和列表加载失败混在一起。可「从大纲创建手稿」（带当前方向）；章节撰写若已选手稿会补 `manuscript_citations`（不改正文）。`POST .../writing/section` 的 `literature` / `citations` 盖 `href` 与 `reproduce_href`。章节引用卡片点进 `literature/:id?page=`，显示当前用户在读百分比；已选手稿时带 `?ms=` 以便阅读器回跳，并可「去复现」。写回手稿为替换选区或追加到标题下。生成不等于写回。写回成功须展示摘要（文末追加 / 追加到某节 / 替换选区预览 + 版本号）并回跳手稿。点「导师式批注」后页内列出 `manuscript_comments`（非官方查重）。译润页头：「改这段文字，再选写回笔记或手稿。」只做译/润/拓，文案链到写作页（带当前 `?ms=` / `?lit=`）；界面分「运行 / 载入原文 / 写回目标」三组，写回用单选：不写回、手稿、已有笔记、作为新笔记。载入手稿不等于写回手稿。`?lit=` / `?note=` / `?page=` / `?ms=` 预选；`?note=` 首次自动载入笔记；仅 `?ms=` 时首次载入手稿正文并默认写回手稿（仍须选手稿写回方式）。写回成功用与写作页同一套成功条（摘要 + 芯片），笔记回阅读器 `?panel=notes`，手稿回同一篇，并写明改了哪一节或哪一段。

手稿编辑：主列 Markdown 预览，侧列**学位节点条常驻**，其余用 `?tab=claims|cites|comments|review|versions` 一次只开一块（禁止新批注产品）。有 `?comment=` 先开评论栏，否则主张追踪。主张追踪识别 `\cite` / `[@key]` / 词边界是否点名、方法卡主张是否写入正文；主张与「去生成」跳阅读器对应页并带 `?ms=` 可回手稿；无卡则链到阅读器生成；每条引用挂最近复现，「查看复现」进详情，「去复现」进该文献的复现列表。参考文献标题同样带上次页码、在读进度与去复现。模拟评审明示非官方查重；再次运行替换上次 `review_sim` 批注，并标出未点名引用。Overleaf 挂在版本栏。仅作者可改正文、恢复版本并看到「未保存」；导师改状态。恢复带可选冲突戳，冲突 409。状态为已发表时可「加入文献库 / 知识库」（同一手稿再次点击幂等，不新建归档库）。列表支持 `?direction_id=`。

知识库：`?tab=docs|ask|terms` 分栏，不堆文档/问答/术语三块。文档栏 Dragger、分页、索引状态可读；失败可重试切块；等待/切块中自动刷新。问答栏：无已索引文档提问时说明原因。综述与问答引用盖 `href` / `reproduce_href`（可点上次页，显示本人在读进度，并可去复现）。文档表看来源文献并可点进阅读器。未接向量模型时白话写「简易检索」。

进度页头：「先看学生在读与手稿。」零成员时「还没有学生。去成员页发出邀请。」成员卡若在读/手稿/任务皆无，写「组员读了文献会显示在这里」。

### 实验任务

文献调研创建可选关联文献与数据集对象。创建 / 暂停 / 取消 / 改进的提示走返回 `feedback`，工人未开不得假装已开跑。详情「组内注入」优先 `injected.literature`，标题带上次页或方法卡页。注入文件写在作业根目录与 `workspace/`，提示词与 OpenHands 会读 `lab_context.json`。问题旁注要求引用已关联标题，未用须标明。引擎 `sys.exit(0)` 且已有必填 `plan.md` / 文献综述才记完成；缺文件或未交代组内文献走现有失败卡。中断点记为暂停，禁止显示成崩溃。需要 GPU 而管理员为 off 时文献调研停在 `awaiting_gpu`，不启动图、不伪造指标；列表可用 `?status=`。等 GPU 时可点「恢复」重新入队；GPU 仍关则再次等待，不得当成成功。管理员把 GPU 改为 internal/external 后，等待中的文献调研/复现改回 `pending` 入队，管理页显示等待计数、不在本页开跑。工人未开时 `pending`/`queued` 仍可点「恢复」当场再跑。复现等 GPU 或无工人已入队同样可「恢复」（不是改进一轮）。子图进度优先数作业 `states/step_*.json`，不要只靠消息里的 Starting/Completed。真复现从文献 + 数据集下拉选择；未填声称时从最好方法卡填入，卡片标明来源（用户 / 方法卡），禁止把声称当实测。方法卡页码可进阅读器（SPA，带 `?page=`）。声称与实测分卡，并有对照表；无实测禁止「成功完成实验」。`blocked` 链到登记数据集；`awaiting_gpu` 只提示联系管理员开启 GPU（平台管理员可进管理页），禁止链到数据集、禁止伪造指标。无 PDF / 仅摘要 / 扫描件时详情警告条写清「打开文献上传可复制 PDF」，不要当成复现引擎坏了。「改进一轮」带上一轮诊断再实现，不是从读取论文重来。复现列表显示文献标题与数据集（文献链上次页），无 PDF / 仅摘要时「引导」列回阅读器；可用 `?status=` / `?literature_item_id=` / `?dataset_id=` 筛选（实验资产，不是新登记处）。详情实时流断开后改为定时刷新并可重连，不假装进度还在推送。轮次表展示日志摘要。

### 协作

成员：页头一句说明。导师主操作是「邀请加入」卡片（邮箱 + 角色 + 发出后展示/复制链接）。「再建实验室」收在折叠次要入口。方向在「我的」条上选定（已有 `PUT .../me/direction`），职称在下表改，不与邀请抢位。学生看不到邀请、改角色、移出。成员表显示**职称/年级**（不是第三角色）：学生可改自己的，导师可改任何人。方向列只读，点方向名进枢纽。**点姓名进进度成员进展**，点方向名进枢纽，不要另开档案页。方向：学生只读列表，加载失败可重试。**点方向行进入详情枢纽**（同页抽屉或 `/labs/:id/directions/:dirId`，侧栏仍高亮「方向」）：成员（可进进度时间线，姓名旁显示职称/年级）、该方向成员进行中的任务（可恢复）、在读、手稿、学位节点（可填截止日期、可挂手稿、归属人或导师改状态；过期标出）、文献深链 `/literature?direction_id=`、手稿 `/manuscripts?direction_id=`、图谱 `/graph?direction_id=`。禁止单独的地图/归档导航。顶栏跳转还可落到方向 / 组会 / 数据集 / 资料 / 日志。组会点行开 Drawer，列表显示行动条数；从通知进入时带 `?open=` 自动打开该纪要；打不开时有可读错误。行动项行带 `?line=` 高亮纪要原文，并可点到看板 `?open=`；看板任务可回跳同一纪要行。看板支持 `?assignee=none` 看待认领；学生可认领未指派任务。资料库与工作日志同样支持 `?open=`，并可被顶栏 jump 搜到。资料库拖拽上传。统计指标卡含本月事件。工作日志标明自愿。数据集是一等对象，详情可关联文献；列表显示说明（可回退来源备注）、文献调研/复现分项次数（点进已筛列表）与关联文献标题（回上次页）。用量行带 `next_step` / `can_resume`，走现有恢复。引用图谱仅本实验室节点，可按方向过滤。周报导师看全组、学生看自己；可选邮件，不接企微。

### 账户

通知深链（文献带上次页码；手稿批注带 `?comment=`；方向落到枢纽而不是方向列表）。通知列表失败可重试。个人 / 实验室 / 管理页模型共用 `LlmKeyForm`：中文标签、服务商预设回填地址与模型、回显已保存掩码，测通针对上次保存的配置。凭据可标 **云端 / 内网**；看图 / 向量 / 重排序收在进阶。测通 `ok:false` 必须是错误提示并带分类，不能 toast 成功。管理页 `/admin` 分三块：**开通**（机构 + 实验室）/ **模型与算力**（平台模型 + 实验 GPU）/ **人员与记录**（用户、审计、用量须有标题）。页头检查清单可点：待审机构 → 平台模型未保存 → 实验算力仍关。GPU 选项中文：关闭 / 实验室集群 / 外接集群。GPU 栏显示文献调研/复现等待计数；开启后重新排队，不伪造指标。工人未开时另列已入队，不写进等待列表。驳回用 Modal。加载失败可重试。申请页同意项旁补全组都能看见一句。开通进度：已开通未进组不要写「可进入工作台」却无按钮；刷新按真实状态提示，不把「管理页点修复」写给申请人。成员页「我的」方向/职称与表格不同时提供两套编辑。

## 11. 整体交互体验（H1 合同）

产品交互按「实验室 OS」设计：先定位对象，再读写，再跑实验任务。禁止把主路径做成聊天框或仪表盘装饰。

### 11.1 四种页面状态

每个列表页与对象页必须可区分：

| 状态 | 表现 | 禁止 |
| --- | --- | --- |
| 加载 | `Spin` + 一句「正在打开…」 | 空白白屏 |
| 空 | 一句下一步 + 可点链接（`EmptyHint` / `GuideList`） | 「No data」或英文 empty |
| 失败 | `Alert` 或 `message.error`，分类错误 `[分类] 说明` | traceback、无限转圈 |
| 有数据 | 对象标题可点；状态用中文 Tag | 露出 UUID 当主标题、露出内部 verb |

切换实验室：Query 清空，落地页按角色（导师进度 / 学生首页）。会话过期：refresh 失败回登录。

### 11.2 对象合同

一条科研对象在全产品只有一个 URL。通知、进度动态、成员时间线、首页未读必须落到同一 URL。

| `object_type` / verb 前缀 | 落地 |
| --- | --- |
| literature / reading / note / analysis | `/literature/:id`（可选 `?page=`） |
| manuscript | `/manuscripts/:id`（评论可选 `?comment=`） |
| writing（无手稿 id） | `/labs/:lab/writing` |
| dataset | `/datasets/:id` |
| research_run / `run.` | `/runs/:id` |
| reproduce_run / `reproduce.` | `/reproduces/:id` |
| task | `/labs/:lab/tasks?open=:id` |
| meeting | `/labs/:lab/meetings?open=:id`（纪要行可选 `&line=`） |
| file | `/labs/:lab/files?open=:id` |
| work_log | `/labs/:lab/work-logs?open=:id` |
| kb | `/labs/:lab/kb` |
| direction | `/labs/:lab/directions` 或 `/labs/:lab/directions/:id` |
| language | `/labs/:lab/language` |
| 其他且有 lab | `/labs/:lab/cockpit` |

实现：`web_next/src/err.js` 的 `noticeHref`。后端 `activity_events` 必须带 `object_type` + `object_id`。心跳不进动态、不进通知。

### 11.3 反馈层级

1. **页内持久：** GPU / 缺数据 / 未保存 / 等待子图 → `Alert` 或 `FeedbackStrip`（金=warning、红=error、玉=success）。
2. **操作结果：** 保存、邀请、入库 → `message.success`；创建 / 恢复 / 暂停 / 取消 / 改进 / 开 GPU → `tellFeedback` 跟 `feedback.tone`；权限/额度 → `message.error(formatError)`（额度带 `next_step`）。
3. **后台进度：** SSE 更新同一详情对象，不新开聊天。暂停、恢复、取消始终在工具条。写操作按钮忙碌防连点。

动效：悬停 120 毫秒，面板和消息出现 180 毫秒淡入并上移 4 像素。尊重系统「减少动效」。只用在消息、面板、悬停。禁止霓虹进度环和大面积动画。Ant Design `processing` Tag 仍表示「正在」。

### 11.4 键盘与触屏

- 「跳到内容」跳过顶栏与侧栏。
- 品牌、铃铛、账户菜单可键盘激活；`:focus-visible` 墨绿 2px。
- 手稿作者 `Ctrl/⌘ + S` 保存；未保存关闭标签触发浏览器确认。
- 主路径不依赖 hover：进度整卡可点，标题 `stopPropagation` 进对象。
- 900px 以下：双栏 / 看板 / 对象页改单列；侧栏折叠；PDF 区缩短。

### 11.5 角色与语气

按钮按角色隐藏，安全以后端 403 为准。学生看不到邀请、改角色、移出、方向 CRUD、实验室 Key。导师改手稿状态，作者改正文。统计与本周事件是中性计数，不做排名、红灯、催促文案。工作日志标明自愿。

## 12. 分模块交互流

### 认证

登录：邮箱 + 密码 → 按角色落地。邀请：先展示实验室名与全组都能看见条款 → 勾选 → 设密 → 同角色落地。过期/已用 token 用 Result，不是空表单。

### 工作台

学生只有一个方向时不在工作台停留。多个方向时工作台只列出方向名和「在找什么」。最近阅读与未读通知不再把「去复现」当主操作。方向选择保存后进入该方向。三句日志提交成功后清空输入。加载中为转圈加「正在打开工作台…」。

### 进度（导师主路径）

登录 → 进度（0 次额外点击）→ 学生卡（1）→ 在读或手稿标题（2）到达正文。在读可去复现（该生上次页）。卡片网格；动态与时间线同一套 `ActivityLine`。本周事件不含心跳、知识库问答与综述。语言写回对象后不再另打 `language.done`。加载中为「正在打开进度…」。引导完成后不再占据首屏。

### 文献

检索 / DOI / BibTeX / PDF / 捕手分入口。库表过滤写入 URL（含 `?has_pdf=0` 看待上传全文）；主表「全文」列区分无 PDF / 扫描件 / 仅摘要，点进阅读器 `?panel=card`。「按方向推荐」Tab 调未读推荐并列出本方向未读。方向列表失败可重试，未选方向时外源按全部方向关键词推荐。阅读器对象页：主列 PDF + 「看中文」本页译文，侧列在读条 + `?panel=` 分栏（这篇怎么做 / 笔记 / 辅导，不堆四张卡）。翻页防抖写入进度；`?page=` 滚 PDF。无 PDF / 文件缺失 / 无法渲染分开展示，并指向上传可复制文字版。工具条可去写作 / 开始复现（落到 `/reproduces?literature_item_id=`，创建表预选该篇）。译完本页才「拿去改」。自己的笔记可去译润（带绑定页）。扫描件 unusable 时提示换可复制 PDF。方法卡仅摘要或无依据摘录时侧栏警告条写清下一步，不要当成分析坏了。对比结果除表格外展示结构化 json（方法/数据/指标/主张）。已发表手稿入库的条目标明来源。

### 写作 / 语言

写作工作台独立成页。`?lit=` / `?ms=` 预选并在改选题时写回网址；已选文献芯片回上次页并可去复现。未选文献时用骨架大纲并返回 `notes=未结合文献`（含「相关工作」）；选了文献但无方法卡返回 `notes=未结合方法卡，仅题录大纲`；有最好卡则大纲吃主张/方法。大纲失败不占用列表 `LoadFailed`。「从大纲创建手稿」可带当前方向；章节写回走服务端（冲突 409 + 版本快照，成功后刷新手稿列表）。章节 `citations` / `literature` 带 `href` 与 `reproduce_href`。「导师式批注」写入并展示手稿评论。语言工作台只做译/润/拓，写回必须带 `expected_updated_at`，可从原文选区填替换片段。写回目标三选一（外加不写回）：手稿 / 已有笔记 / 新笔记；仅作者可改自己的笔记，冲突 409。阅读器 `?lit=` / `?note=` / `?page=` 预选；`?note=` 进入时自动载入并默认写回该笔记。仅 `?ms=` 进入时自动载入手稿并默认写回手稿（须再选写回方式）。手稿页可去语言工作台并带回 `?ms=`。仅选文献且目标为「不写回」不自动建笔记。新建笔记绑定页码；写回成功条回阅读器笔记栏或同一手稿。

### 手稿

列表行进编辑器，并可「去写作」（`writing_href`）；支持 `?direction_id=`。对象页：主列编辑/Markdown 预览，侧栏「去写作」。侧列 `?tab=` 分栏：主张 / 引用 / 评论 / 评审 / 版本（Overleaf 在版本栏）。评论选区摘录 + 定位到 textarea；`?comment=` 先开评论栏并滚动高亮该条。**模拟评审（明示非官方查重，通知作者）**。引用标题进阅读器并可去复现。版本仅作者可见恢复。已发表可加入文献库/知识库（幂等）。作者保存与快捷键；导师状态机；组内只读正文。保存/恢复/写回冲突 409 带 `href` 与当前 `updated_at`，页内刷新，禁止选区锁。写作页批注链到同一 `?comment=`。

### 知识库 / 数据集 / 周报 / 图谱

知识库 `?tab=docs|ask|terms`。文档栏 Dragger 上传、分页、索引状态可读；失败/卡住可 `POST /kb/documents/{id}/reindex`。无已索引文档提问返回 `empty_reason=no_indexed`。问答即使无命中也标明 `embed_fallback=hash`。综述与问答引用带 `href` / `reproduce_href`；文档表看来源文献（带上次页码）并可去复现。数据集是一等对象，详情可去文献调研/复现、可关联本实验室文献（点标题回上次页并可去复现）；用量行进现有任务详情；列表显示说明与被文献调研/复现引用次数；登记会通知组内其他导师。周报聚合本周 activity，深链与通知 `noticeHref` 对齐（写作页、组会 / 看板 / 资料 / 日志 `?open=`、数据集对象、文献库 `?tab=recommend` 组内相关、文献对象带 `?page=`）；文献/笔记事件带 `reproduce_href`。不含 `kb.query`。可选邮件，不接企微。顶栏 jump 文献项同样带 `reproduce_href`（选中仍进阅读器）。引用图谱单击选中、双击或标题打开本实验室对象（文献带上次页或方法卡页，并可去复现）；`?direction_id=` 只显示该方向节点。方向抽屉含 `recommend_href`，抽屉内文献标题同样带页码与「去复现」。

### 实验任务（实现备忘）

文献调研：填问题，可选关联文献与数据集对象 → 进详情，详情工具条打开关联对象；注入文献带上次页、复现差距并可去复现。列表行显示文献标题与数据集，文献可去复现。真复现：选文献 + 数据集 → 详情方法卡 / 论文声称 / 实测 / 差距。未填声称时从最好方法卡填入并标明来源。`claimed_metrics` 永远标成「论文声称（非实测）」。无实测或诊断 `not_run` 禁止「成功完成实验」；失败分类金标区分测试桩 / 无 Docker / 无 GPU / 解析失败，不要一律「容器环境」。文献详情 / 辅导展示同一条 `latest_reproduce` 证据。`blocked` 用提示条并链到登记数据集；`awaiting_gpu` 只写「请联系管理员开启 GPU」，管理员可进 `/admin`。改进一轮后详情仍保留文献标题与数据集。首页进行中的复现卡显示文献标题。实时流断开后提示定时刷新并可重连。

### 协作

看板三列，按钮改状态（H1 不拖拽）。组会粘贴纪要 → 行动项派发 → 看板出现；通知带回放 Drawer。纪要行 `?line=` 与看板 `?open=` 互跳。看板 / 资料 / 日志通知带 `?open=` 高亮。资料同名升版本。统计：总量 + 本月事件 + 方向/成员表 + CSV + 复现诚实计数（已实测 / 未跑 / 测试桩，点进现有复现列表）；表内名称可点进现有研究方向 / 文献过滤 / 成员进展。成员职称出现在成员表、方向抽屉与进度卡片。文献/笔记通知与动态可「去复现」；手稿评论仍只进 `?comment=`。

### 账户

通知列表与铃铛同一深链（手稿批注可带 `?comment=`）。Key 页加载失败可重试，只显示掩码并可测通。管理：用户启用、GPU、平台 Key、审计时间；删除实验室需确认。文献捕手选项页可用邮箱登录拿 JWT（仍可粘贴），401 自动刷新；知网 / IEEE 弱 meta 仍降级。页脚版本为 0.2.0。

## 页焦点与用词

网址参数和接口字段不动。人看见的字按下面说。长口径、例外、邮件不跟筛选，只放标题旁的问号里。页头副文案不超过一句。一页一个主按钮。

用词：

- 还没复现就写成成功 → 写了结果，组里还没跑过
- 综述没写到 → 综述没提到
- 核心文献还没写进正文 → 这几篇还没写进正文
- 方法卡 → 这篇怎么做。按钮叫提炼
- 工人未开、已入队 → 还没开始跑
- 等待实验算力 → 在等机器
- 尚无实测 / 已有实测 → 还没跑出结果 / 已经跑出结果
- 测试桩 → 试跑，不是正式结果
- 简易检索 → 普通搜索
- 全组都能看见 → 组里的人能看到阅读进度和手稿。只有作者能改手稿

每页只回答一个问题：

- 工作台：今天先做这一件
- 进度：谁在读，谁在写
- 文献库：打开一篇来读
- 阅读：就读这一页
- 写作：先把这一步写完
- 手稿：改这一篇
- 文献调研：这个问题查到哪了
- 复现：这篇跑出来没有
- 方向：这个题目现在怎样
- 周报：这一周发生了什么
- 统计：从读到发表有多少
- 看板：我的待办
- 组会：这次会定了什么
- 资料：找到这份文件
- 图谱：这篇和谁有关
- 数据集：登记一份数据
- 个人模型：密钥能不能用
- 管理：先审待开通的机构

点击：成功、失败、警告、现在不能做，都要有一句话。按钮按下时转圈。禁用按钮点下去要说明原因。复制成功写「已复制」，失败写「没复制上，请再试一次」。心跳和自动记页码不弹窗。实现见 `press` / `PressButton` / `copyText` / `whenBlocked`（`web_next/src/ui.jsx`），展示层用 `humanize`（`web_next/src/err.js`）把接口里的旧说法换成上面的字。

写作页同时只展开当前一步（选题、章节、写回）。其余步骤点标题再打开。引用和批注默认收起。翻页、对比、提问、提炼、邮件开关和实验算力，在不能点时说明原因。上次大纲、章节、译稿、对比、评审没加载出来时说一声，不假装没有。

文献调研里「带上的文献」是这次一起查的组内论文，不说注入。复现和手稿列表用「有没有跑出结果」「正文和结果」，不说诚实。手稿推到 Overleaf 时，访问令牌只用于这一次。个人模型先保存再测。数据集页先说这份数据是什么。
