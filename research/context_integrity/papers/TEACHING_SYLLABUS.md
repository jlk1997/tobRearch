# 教学大纲：大模型原理 × 训练调参 × 文本水印/加密 × 智能体安全 × 理论审视与创新

适用：博士生，方向为 AI 智能体安全；实验室底子是 **AI 安全 + 文本加密/水印**。  
原则：**智能体安全不是跳过大模型的捷径。** 压缩、注入、认证，全部踩在 tokenizer、注意力、对齐、解码和完整性原语上。不会训练与调参，就写不出站得住的实验；不会水印与加密，就和实验室脱节；**只会顺着主流理论往前背，就写不出优化，也看不出论文一为什么成立。**

教材四层：

1. 原理与训练：Vaswani / 预训练-SFT-RLHF / LoRA 与超参
2. 实验室主业：文本水印、文本完整性/加密、隐写与检测
3. 本仓库课题：OpenLens 压缩管线、论文一/二/综述
4. 审视与创新：下一词理论的三层缺口、五营替代路线、可测量的优化缝

## 阶段 I　地图、数学、流水线

### 第 0 课　这门课的地图：四块积木怎么拼

**目标：** 画出课题为什么必须同时懂模型、水印/加密、智能体、以及「理论哪里不够」。

```text
大模型原理 + 训练调参
        │
        ├─ 决定：窗口为何要压缩、rerank 按什么打分、对齐为何挡不住管线
        │
文本水印 / 文本加密与完整性  ← 实验室已有
        │
        ├─ 水印：内容从哪来、压缩后印还在不在（溯源）
        ├─ 加密/MAC：角色与来源能不能伪造（认证）
        │
智能体压缩管线（OpenLens） ← 本仓库实验床
        │
        ├─ 论文一度量攻击；论文二认证；第三条水印过压缩
        │
审视与创新
        │
        └─ 引擎会流畅地错 → 系统层必须可验证；换骨架往往补不上角色
```

**审视：** 「只做 prompt injection、不碰训练和水印」不是捷径，是开题偏科。  
**缺口卡片示例：** 假设「模型对齐了就不会听注入」→ 破了：压缩把角色撕掉 → 补丁在管线不在 RLHF → 本仓库可测。  
**验收：** 1 分钟说清为什么开题必须四块一起在场。

### 第 1 课　必用数学 + 下一词流水线

**目标：** 后面公式出现时不慌；能用自己的话走通「字 → 编号 → 数 → S → 打分 → 归一化 → 选字」。

必会：

- 条件概率、贝叶斯、交叉熵 \(-\sum y\log\hat y\)
- KL 散度（RLHF / 水印检测里都会再见到）
- 梯度、链式法则、学习率的直觉
- 词表是名册，字是名字，编号是工号，一排数是档案
- 整句各排一起进网络，得到 **一排 S**（不是词表里某一行）
- S 和每个字那排乘加，得到整表 logits；先对全部做 softmax；再用概率选下一个字（可取最大，可抽）

**接到水印：** 绿名单水印改的就是打分之后、softmax 之前的分布。  
**接到训练：** 预训练几乎就是「下一个编号的交叉熵」。

**审视：** 这条流水线里没有「真假」工位。有错的概率不自动等于方向错了；怪的是错会长得像对。预告三层错误（第 11 课展开）：抽奖、目标、累积。  
**验收：** 交叉熵在预训练和水印检测里各扮演什么；S 为什么不是词表里的一行。

---

### 第 2 课　神经网络到序列模型

**目标：** 从感知机走到「为什么必须用注意力」。

必会：线性层、激活、反向传播直觉、过拟合与正则、RNN/LSTM 的长程遗忘、Seq2Seq + 注意力的动机。

**审视：** RNN 忘得远，注意力能查全句，但代价是长度平方级算力——这是第 5 课必须压缩、第 18 课有人换骨架的根。注意力解决的是「看得到」，不是「说得真」。  
**缺口卡片方向：** 「只要看得到全文就不会忘角色」——压缩一做，角色先没了。  
**验收：** 用「查字典」解释注意力，对比 RNN 为何难扛长上下文。

## 阶段 II　Transformer 与大模型原理

### 第 3 课　Tokenizer 与词表

**目标：** 攻击和压缩的计量单位是 token，不是「字」。

必会：BPE / WordPiece、词表大小、`bos`/`eos`/`pad`、中英文切分、token ≠ 字数。

**接到论文一：** 预算 \(B\)、切块，全是 token。  
**接到水印：** 印嵌在 token 选择上；换 tokenizer 检测会垮。  
**接到 OpenLens：** `vector_search` 按 token 截断。

**审视：** 词表印死，模型不能发明第 N+1 个字，但能把旧字排成没出现过的假事实。离散词表不是安全性。  
**验收：** 为什么「堆查询词」能抬高 rerank 分，却也可能先把自身 token 撑爆。

---

### 第 4 课　Transformer 结构（要能画图）

**目标：** 能手画一层：嵌入 → 位置 → Multi-Head Attention → FFN → 残差 + LayerNorm。

必会：

- \(Q,K,V\) 与 \(\mathrm{softmax}(QK^\top/\sqrt{d})V\)
- 因果掩码
- 多头在做什么
- 残差为何能训深

阅读：Vaswani et al., *Attention Is All You Need*（先读第 3 节）。

**审视：** \(O(n^2)\) 是工程税，不是理论破产。A 营（Mamba / RWKV / xLSTM）换发动机，**下一词目标和幻觉机制几乎原样**。本课先会公式，第 18 课再对照。  
**验收：** 遮住论文，写出注意力公式并解释 \(\sqrt{d}\)。

---

### 第 5 课　上下文、KV Cache、为何一定要压缩

**目标：** 从复杂度解释论文一的存在理由。

必会：自注意力对长度 \(n\) 是 \(O(n^2)\)；KV Cache 省重复计算但显存随 \(n\) 涨；窗口仍会被工具返回撑爆。

压缩的三条工程路：

1. **删除型：** 切块 + rerank，OpenLens `vector_search`（论文一主战场）
2. **生成型：** 摘要 compact（开放问题：MAC 盖不住摘要）
3. **外置型：** RAG / MemGPT 换页（PoisonedRAG 的战场）

**接到水印：** 删除型丢掉带印 token；生成型重写从而抹印。  
**接到加密：** 删除型可用授权裁剪；生成型必须另做可验证摘要。

**审视：** 压缩优化的是「和当前问句像不像」，不是「这段还是不是原来的角色」。理论不足就在这里——相关性 ≠ 完整性。这是论文一的创新根，不是形容词。  
**缺口卡片方向：** 可验证摘要、带角色的裁剪、压缩后水印还在不在。  
**验收：** 三种压缩各举一个系统例子，指出水印在哪一种里最容易死。

---

### 第 6 课　解码：温度、top-k、top-p、重复惩罚

**目标：** 调参第一块，也是水印嵌入点。

必会：贪心、温度 \(T\)、top-k、nucleus (top-p)、beam。  
\(T\to 0\) 近乎确定；\(T\) 大则乱。

**接到水印：** Kirchenbauer 在采样前给绿名单加偏置 \(\delta\)。  
**接到智能体：** 路由模型低温时，更容易原样吐出文献里的 `DECISION: END`。

**审视：** 这是三层错误的 **抽奖层**。贪心压得住随机，压不住「目标层」的流畅胡说。水印若只活在「从左到右、改 logits」，B 营扩散一换采样顺序，印就要重做——先记账，第 19、33 课再设计实验。  
**验收：** 画出「logits → 加偏置/加水印 → softmax → 采样」。

## 阶段 III　训练、对齐、微调、调参

### 第 7 课　预训练目标与语料

**目标：** 知道底座从哪来，能力与毒性从哪来。

必会：因果语言模型 \(p(x_t\mid x_{<t})\)、数据配比、重复、评测污染、Scaling Law 的定性结论。

**接到安全：** 间接注入能成功，因为预训练就在学「续写网页/论文里的祈使句」。

**审视：** 这是三层错误的 **目标层**。目标是续写，不是求真。Kalai：任意罕见事实有统计胡说下界；系统事实（算术、反复出现的书目）没有同样的必然性，更吃工具。对齐（第 8 课）改偏好，不改这个目标。  
**验收：** 为什么对齐不能从根上取消压缩管线攻击。

---

### 第 8 课　SFT、RLHF、DPO（对齐栈）

**目标：** 分清三阶段，能说出每阶段优化什么。

必会：

- SFT：示范对话上的交叉熵
- RM + PPO（RLHF）：奖励模型，KL 惩罚防塌
- DPO：直接在偏好对上优化

阅读：Ouyang *InstructGPT*；Rafailov *DPO*（先读图和损失）。

**接到论文一相关工作：** SecAlign、指令层级改的是对齐，**不改压缩器**。  
**接到水印：** 对齐后采样分布变了，\(\delta\) 要重标定。

**审视：** 「对齐了就不会听注入」假设角色通道还在。压缩一撕，假设破产。评测惩罚「我不知道」会把模型训成宁猜——目标层的社会放大。  
**验收：** 一张表对比 SFT / RLHF / DPO 的输入与损失。

---

### 第 9 课　微调技术：全参、LoRA、QLoRA、提示微调

**目标：** 能设计一组可复现的微调实验。

必会：LoRA 的秩 \(r\)、\(\alpha\)、作用矩阵；冻结底座；灾难性遗忘。

**接到课题：** 「压缩后仍保留水印的解码头」「拒绝对伪造 system 前缀遵从」都是 LoRA 实验，不是只写规则。

**审视：** 微调能改局部偏好，不能给模型装上世界模型。若题目需要「换交通规则」，LoRA 不够，要走第 20～22 课的系统层或明确写局限。  
**验收：** 写一份 LoRA 配置清单（\(r,\alpha,\) 学习率, 批大小, 步数, 目标模块）。

---

### 第 10 课　调参实务（必须动手）

**目标：** 建立正确的调参习惯。

必懂：

| 超参 | 太大时 | 太小时 |
| --- | --- | --- |
| 学习率 | 损失爆炸、遗忘对齐 | 不收敛 |
| batch / 梯度累积 | 显存爆、泛化差 | 噪声大 |
| 最大长度 | 显存与压缩触发点 | 截断任务 |
| warmup / 权重衰减 | 早期不稳 | 过拟合 |
| 温度 / top-p（推理） | 胡言、水印不稳 | 重复、死板 |
| rerank 预算 \(B\)（OpenLens） | 不压缩、攻击面缩小但贵 | 角色坍缩更狠 |

作业（有 GPU 再做，没有先写实验计划）：同一任务三组 lr，画验证损失；记录触发压缩的长度阈值。

**审视：** 「把 \(B\) 加大」不是论文一的防御：成本与窗口仍有限，且 **不恢复角色**。调参优化的是损失和预算，不是完整性。  
**验收：** 解释为什么加大 \(B\) 不能当防御写进论文。

## 阶段 V　文本水印

### 第 12 课　文本水印原理：从零到 Kirchenbauer

**目标：** 能讲清「在采样时藏印、在文本上检测」。

必会：硬/软水印；\(\gamma,\delta\)；z-score；无密钥统计印 vs 带密钥；改写/截断/翻译/二次生成。

阅读：Kirchenbauer et al., ICML 2023；Unigram / SynthID / 去印工作选读。

**审视：** 水印假设「从左到右、改 logits、检测看 token 统计」。压缩是合法的大规模删除 + 重排；扩散是改采样顺序。两个假设都可能破。印证明「哪来的」，不证明「谁签的角色」。  
**验收：** 默写「哈希前文 → 红绿名单 → 加 \(\delta\) → 采样 → z 检验」。

---

### 第 13 课　水印前沿：鲁棒、不可见、去印攻击

**目标：** 知道现在卷什么，避免把 2023 方案当终点。

主题：语义改写下的检测；多比特来源 ID；模型无关检测；去印；与对齐的冲突。

对准论文一问三句：

1. 带印工具返回经 `vector_search` 后，检测还显著吗？
2. 伪造 `System:` 无印却被当成 system，能否当异常？
3. 堆词会不会抬高或破坏印的统计量？

**审视：** 这是实验室 × 压缩管线的 **论文 C 苗子**（溯源，不是认证）。  
**验收：** 200 字：水印证明哪来的，MAC 证明谁签的，为何不能互相替代。

### 第 14 课　水印实验课（结合 OpenLens）

## 阶段 VI　文本加密与完整性

### 第 15 课　密码学最小集（为文本服务）

**目标：** 分清加密、认证、哈希。

必会：机密性 vs 完整性 vs 不可否认；哈希、HMAC、AEAD；对称 vs 公钥；EUF-CMA 一句话；长度前缀防字段注入。

**审视：** 「把上下文加密再送给模型」是错方案——模型还得读明文。要的是完整性（角色绑定）。E 营的「外面卡住」在密码学里就是 MAC / 签名，不是把神经网络训得更诚实。  
**验收：** 为什么加密上下文是错、HMAC 绑定角色是对。

---

### 第 16 课　文本加密、可检索加密、隐写（实验室文献）

选讲（按组内论文替换）：格式保留 / 可搜索加密；语言隐写（威胁模型与水印不同）；可裁剪签名、CES。

阅读：Merkle 1980；HMAC RFC 2104；Steinfeld 等 CES；组内代表作。

**审视：** 压缩 = 授权删叶 = 可裁剪签名的应用场景。HMAC 是最小可用；组里若已有可裁剪/同态完整性，论文二可以升级，这是 **优化点不是装饰**。  
**验收：** 隐写、水印、MAC 各用一句话区分敌手。

### 第 17 课　可裁剪完整性 → 智能体记忆

**目标：** 论文二第 2～3 节的人话 + 公式预习。

必会：叶子 \(\sigma=\mathrm{HMAC}_K(\mathrm{role}\|\mathrm{source}\|\mathrm{content})\)；Merkle 根；失败封闭；信息流（真工具脏内容仍不可升格为 system）。

**接到水印：** MAC 防伪造角色；水印防「同角色换一段假文」。二者叠才完整。

**审视：** 生成型摘要没有叶子可签——MAC 盖不住 compact。这是理论不足，也是第 33 课的优化题（可验证摘要 / 认证压缩）。  
**验收：** 画出「签名 → 压缩删叶 → 验证 → IFC 剥保留字」。

## 阶段 VII　五营替代与可优化缝

### 第 18 课　A 营：换骨架（Mamba / RWKV / xLSTM）

### 第 19 课　B 营：扩散语言与能量模型

### 第 20 课　C 营：JEPA / 世界模型

**目标：** 知道「预测表示、不预测下一词」在攻哪一层怪。

阅读：LeCun 2022 蓝图选读；[facebookresearch/ijepa](https://github.com/facebookresearch/ijepa)；[facebookresearch/vjepa2](https://github.com/facebookresearch/vjepa2)。批评：潜空间塌缩、不接地。

**审视：** 这才是换交通规则。学期内不要重做 V-JEPA。要问的是：OpenLens 的 rerank 预测的是「词面像不像查询」，不是「下一块记忆在任务上该留什么」。  
**可优化：** 压缩器从「像查询」改成「对后续子图有用的表示」——先做小代理指标，禁止空喊世界模型。  
**验收：** JEPA 为什么还替不了对话引擎；和论文一压缩目标差在哪。

### 第 21 课　D 营：HRM / TRM 递归推理

### 第 33 课　从缺口卡片长出新缝（创新工坊）

本课不讲新公式。把第 22 课圈出的那一条写成 **一页实验计划**。下面是课程预埋的缝，允许你改，不允许你空喊。

**D. 水印过扩散 / 非自回归（实验室 × B 营）**

- 缺口：Kirchenbauer 假设从左到右改 logits。
- 测：同一印、同一检测统计量，在自回归 vs LLaDA 类采样上的 TPR/FPR。
- 优化方向：按块哈希、按整句能量、或检测改成与顺序无关。

**E. 可验证摘要 / 认证压缩（论文二不够处）**

- 缺口：生成型 compact 没有叶子可签。
- 测：摘要前后角色/来源是否可核查；失败时是否封闭。
- 优化方向：摘句（可裁剪）优于改写；或摘要模型只许输出已签名句的编号。

**F. 角色保持的删除型压缩（论文一的防御升级）**

- 缺口：rerank 只问「像不像查询」。
- 测：约束「同一 source 的角色不得改写」之后，七类攻击的 ASR / \(L\)。
- 优化方向：先认证再打分；无签叶不得进预算。

**G. 停止条件与路由的非文本判据（PoC5 × D 营思想）**

- 缺口：`DECISION: END` 活在明文里，低温模型会照念。
- 测：把停止改成覆盖率结构字段或隐状态阈值后，控制流劫持 ASR。

**H. 骨架更换复现（审稿防御，不是主创新）**

- 缺口：有人会说「换 Mamba 就没问题」。
- 测：同一压缩语义下 A 营 backbone 的角色坍缩是否仍在。
- 预期：仍在。写进论文一局限或短文。

纪律：选 **一条** 写自变量、因变量、对照、一周能跑的最小实验。禁止并行开五条。
